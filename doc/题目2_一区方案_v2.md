## 1. 题目与定位

### 1.1 为什么是它

单帧 FPP 是动态 3D 的默认选择，但死区（完全无调制光的区域）里相位不可信。2026 年的两篇直接对手已经把"不确定性"占了：

- **HSURE-CFPP**（arXiv:2601.02572）：异方差 + snapshot ensemble + 像素级 UQ；
- **PhiCalNet**（arXiv:2606.17093 / 2607.11928）：conformal UQ 作为诊断 + 证明单帧回归非单射 + photorealistic 基准 FPP-ML-Bench。

**仍空着的位置**：没有人回答"**这个死区在物理上还能不能被证明地恢复**"，也没有人把"**接受这个 3D 点会冒多大风险**"做成一条可执行的判决规则。本课题就做这两件事。

### 1.2 与对手的差异（一句话版）

| 他们 | 我们 |
|---|---|
| 给一张不确定度热图（相关性） | 给**证书**（充分条件，可证明）+ **校准区间**（覆盖率，可检验） |
| 全局/像素级 UQ | **类条件**覆盖（按物理可恢复类分组） |
| 深度回归 | **最优恢复**：证明 harmonic 延拓在给定表面类下是 minimax 最优，网络只需逼近它 |
| 基准是别人的 | 基准是**带标定的**（mm 几何 + 精确相位 GT + 4 个条纹密度） |

### 1.3 边界（与 P3 划清，写进 cover letter）

> P2 回答"**哪些点可以信、以多大概率**"，是离线、统计、可证明的；P3 回答"**这些判断能以多确定的速度交付**"，是嵌入式、系统、确定性的。两篇共用 phasor 与不确定度信号，但不共用实验：P2 用注入式物理退化的标定基准，P3 用带证书的量块与转台。

## 3. 理论与方法

### 3.1 观测模型与三个域

条纹形成（相机侧）：

```
I(x) = clip( A(x) + R(x)·[a + b(x)·cos(φ(x))] + n(x), 0, 1 ),   n ~ N(0, σ²)
```

死区 = **无调制光**（`b→0`）。特别注意：**饱和（clip）与乘性阴影不毁相位**（基波相位不变），实测 2π 失败率 0.000–0.018；**只有全遮挡**才毁（0.105–0.699）。这是本文与"把饱和当死区"的常规做法最不一样的地方。

三个域（**必须分开，混在一起会毁掉全部指标**）：

| 记号 | 含义 | 来源 | 用途 |
|---|---|---|---|
| `Ω_roi` | 测量域（有表面） | 夹具/上一帧/轮廓连续性；基准里由多步最大强度精确给出 | 损失只在域内；域外不许改 |
| `Ω_d ⊆ Ω_roi` | 死区（有表面、无调制光） | 由 CRB 与盲区判据反推 | **主指标只在这里算** |
| `Ω_bg` | 无表面 | `Ω_roi` 的补 | 不参与对错；单列"背景泄漏率" |

> **一个必须写进 Discussion 的事实**：单帧里"被遮挡的暗表面"与"没有表面"物理上不可区分（都没有调制光）。因此 `Ω_roi` **不可能**从单帧里唯一确定，可恢复性分析必须**以 `Ω_roi` 为条件**。这既是限制，也是本文"集合辨识"框架的一部分；并给出消融：`Ω_roi` 单帧估计 vs 给定。

### 3.2 死区相位的最优恢复（C1 的理论核）

**设定**：`Ω ⊂ R²` 为死区，`∂Ω` 上相位可观测（记为 `g`）。表面类

```
K = { ψ ∈ C²(Ω) : |Δψ| ≤ κ }.
```

**引理 1（扭转函数界，对任意形状成立）**：令 `h` 为 `g` 的调和延拓，`u = ψ − h`。则 `u|∂Ω = 0`、`|Δu| ≤ κ`，由极值原理

```
|u(x)| ≤ κ · v_Ω(x) ≤ κ · ‖v_Ω‖_∞ ,      −Δv_Ω = 1,  v_Ω|∂Ω = 0.
```

`v_Ω` 是**圣维南扭转函数**。对圆盘 `‖v_Ω‖_∞ = R²/4 = d²/16`；对宽 `w` 的细条，`v_Ω → w²/4` 的 1-D 极限给出 `‖v_Ω‖_∞ → w²/8`（**与长度无关**）。

**定理 1（minimax 最优）**：调和延拓 `h` 是类 `K` 上的 minimax 估计，最坏误差恰为 `κ‖v_Ω‖_∞`，由极值面 `ψ* = h ± κ v_Ω` 达到。

**推论（证书）**：

```
ρ := κ · ‖v_Ω‖_∞ / φ_tol   ≤ 1   ⟺   该死区被证明可恢复（且用 harmonic 延拓即可）
```

**定理 2（Talenti 比较原理 → 闭式上界）**：等面积集合中圆盘使 `‖v_Ω‖_∞` 最大，故

```
‖v_Ω‖_∞ ≤ d_eq²/16 ,   d_eq = 2√(A/π),
```

等号仅当 `Ω` 是圆盘。**所以 `κd_eq²/16` 是 sound 的闭式兜底，而 `κ‖v_Ω‖_∞` 是紧的精确界。**

**定理 3（宽度律，本文的头条）**：细条死区的 `‖v_Ω‖_∞ → w²/8`，**只依赖宽度**；而等面积的 `d_eq²/16` 随长度线性增长。因此

> **死区的可恢复性由它的"宽度"决定，不由面积（或等效直径）决定。**

**定理 4（negative result）**：若 `κ‖v_Ω‖_∞ > φ_tol`，则存在两个都满足观测的可行表面，其差 > `2φ_tol`；此时**没有任何方法**能保证容差内恢复 → 必须拒绝或补拍。

**定理 5（尺度形式）**：`ρ = κ·T²·(‖v‖_∞/T²)/φ_tol`；把 `κ` 与死区尺寸都按条纹周期 `T` 归一化后，`ρ` 只依赖"死区有几个条纹周期宽"→ 与相机分辨率无关。这是分辨率自适应与跨传感器实验的理论依据。

> **实测校核（已做，零违例）** —— `probes/theory_check.py`（60 样本，圆形，d ∈ {24..96}）：结论符合引理 1，界/实测中位 2.3–10.2×，**0 违例**。
> `probes/theory_sliver.py`（7 种形状 × 11 个对象，`φ_tol = π/10`）：
>
> | 形状 | 面积 | `d_eq` | `w_eff` | 扭转界 | `d_eq` 界 | 实测 | 扭转认证 | `d_eq` 认证 |

### 3.2.1 两层测量（本方案的核心结构）

| 层 | 条件 | 保证 | 预期覆盖 |
|---|---|---|---|
| **Tier-1 已证明** | `ρ = κ‖v_Ω‖_∞/φ_tol ≤ 1` | 死区内**每一个**可行表面都在容差内（概率 1，无分布假设） | **细条/阴影型**死区覆盖高；圆盘型覆盖低 |
| **Tier-2 已校准** | `ρ > 1` | 类条件 conformal：`P(|φ̂−φ| ≤ τ_c σ̂ | class) ≥ 1−α` | 其余全部 |

论文口径：**"死区能否被证明恢复，取决于它的宽度而不仅是大小；能证明的给保证，不能证明的给覆盖率，两者合成一条接受/拒绝规则。"**

### 3.2.2 W1 要做的三件理论工作（已按评审意见修正）

1. **扭转函数证书**：把 `κ‖v_Ω‖_∞` 写成可计算的形式（每个死区一次稀疏 Poisson 解，或用 1-D 宽度近似 `w_eff = √(8‖v‖_∞)`），并给出 Talenti 兜底。**已数值验证 sound（7/7 + 60/60 零违例）**，W1 只需补严格证明与 `w_eff` 的快速估计。
2. **C¹ 版本（次要，仅 1.4427×）**：加上 `u|∂Ω = ∂_n u|∂Ω = 0` 后，圆盘上的极值为 `κR²ln2/2`（直径），即证书半径收紧 **1/ln2 = 1.4427 倍**（Certified diameter × 1.201）。**已数值验证（1.4426）**。注意：初稿曾误以为 4 倍，已更正；`|Δψ|≤κ` 类下 C¹ 不可能带来 4×。
3. **极值面可达性**：构造 `ψ* = h ± κ v_Ω` 并确认实测误差 = 界（Thm 1 的另一半）。

> **度量口径的连带修改**：数据分层与 `d_eq` 相关的所有地方改用 **`w_eff = √(8‖v_Ω‖_∞)`（扭转宽度）** 与**长宽比**。`d_eq` 只作为"圆形上界的参考"保留。

### 3.2.3 最优恢复参考 ORR 的严格定义（C2 的对标物）

"包络"这个词在初稿里没定义死，这里写死，避免审稿人质疑"拿一个松弛界充当信息极限"。

```
ORR(Ω_d) := h ,   h|∂Ω_d = ψ_GT|∂Ω_d ,   Δh = 0 在 Ω_d 内
（离散：用 GT 边界值做 Dirichlet 调和延拓；使用**无噪声** GT 边界，因此 ORR 不含噪声项）
```

- **ORR 的定义是"只给边界值（C⁰）时，minimax 最优估计的实际误差"**，由定理 1 它等于最优恢复算子；
- 它**不是**信息论下界：若半影带（`≥6 px`，`m<0.3`）里还有残余条纹，方法**可以**低于 ORR。因此本文的口径是：
  - **主指标**：网络误差 vs ORR 的比值（`≤1.15` 为达标）；
  - **若某方法低于 ORR**，那是"半影带确实携带信息"的**证据**，单独报一列 `gain over ORR`，并检查是否用了 GT 泄漏；
- 另设一个**噪声无关**的对照：`ORR_noisy` = 用带噪的实测边界值做调和延拓，用于区分"边界噪声"与"模型误差"。

> 三个量一起报：`Identity`、`ORR`、`Ours`。这样"逼近包络"这句话才有可核对的定义。

**因果链必须写清（v2.3 新增，否则审稿人会问"既然有调和延拓为什么还要网络"）**：

| 量 | 边界从哪来 | 用途 |
|---|---|---|
| `ORR` | **GT 边界**（无噪声） | 性能上界标杆，只在评测时出现 |
| `ORR_noisy` | GT 边界 + 实测噪声 | 分离"边界噪声"与"模型误差" |
| **`h_input`** | **单帧 FTP 解调的观测边界**（含噪声、可能含残余跳周） | **网络的实际输入基底** |

于是 `Δψ_net` 的物理职责有**两条**，论文必须同时写：
1. **补全死区内未知的曲面起伏**（`κ‖v‖` 那一部分，理论上不可从边界得到）；
2. **抵消 `h_input` 因单帧边界噪声 `ε_g` 产生的调和基底偏差**（引理 2：偏差 ≤ `δ_g`，但它是**平滑且可学**的）。

第 2 条是网络存在的直接理由，也是对评审"为什么不用 harmonic 就完了"的正面回答：harmonic 用**真**边界时是 minimax 最优，用**噪声边界**时不是——网络学的正是这个差。实验上要用 `∥Ours − ORR∥` 与 `∥ORR_noisy − ORR∥` 两条曲线证明第 2 条确实被学到了。

> 口径：Tier-1 的判据可以等价地读成"**死区两侧的相位落差小于约 0.8 个条纹周期**即被证明可恢复"（`κd² ≤ 16φ_tol = 5 rad`）。这个直觉很适合放进摘要与 Fig.1。

**实现细节（审稿人会问）**：
- `κ` 从**观测域**估计：`κ̂ = P99(|Δφ̂|)` 在 `Ω_roi \ Ω_d` 的邻域上；报告 `κ̂` 的敏感度（`κ̂` 偏小 → 证书不保守 → 必须给 soundness 检查）；
- `d` 用 `Ω_d` 的**等效直径** `2√(A/π)`（不是最大内切圆，二者都给）；
- `φ_tol` 由测量任务给定（本文报 `π/10` 与 `π/50` 两档）。

### 3.3 信息界（部分可观测的另一支）

对**截断**（clipped）观测，`I = clip(A + B cos φ + n)`。**注意：单像素单帧下 `(A, B, φ)` 三个未知量使 Fisher 信息矩阵奇异**，所以论文必须写成**条件** Fisher 信息（给定由邻域估计的 `Â, B̂`）：

```
J(φ | Â, B̂) = (1/σ²)·E_n[ (∂/∂φ clip(Â + B̂ cos φ + n))² ],
σ_info = 1/√J(φ | Â, B̂).
```

这一点必须写死，否则理论审稿人会直接指出 FIM 奇异。它把"饱和/低调制但仍有信号"的区域量化：`σ_info` 有限（可修复），而盲区不给信息（交给 3.2）。**两条界各管一段**，这正是"为什么需要两个下界"的答案。

### 3.4 ρ 与三分类

| 类 | 条件 | 含义 | 处置 |
|---|---|---|---|
| **R** reliable | `σ_info ≤ σ_allow` | 直接解就够 | 接受 |
| **P** partially recoverable | `R` 不成立，且（`ρ ≤ 1` 或 `σ_info ≤ σ_dead`） | 有救：证书覆盖，或信息仍够 | 接受（附区间） |
| **U** uncertified | 盲区且 `ρ > 1` | 没有证书 | 交给 conformal；风险超限则拒绝 |

`σ_allow`、`σ_dead`、`φ_tol` 三个阈值由任务给定并在文中列表。分类标签**只由观测量（m、σ̂、`‖v_Ω‖_∞`、κ̂）产生**，不用 GT → 不循环。

### 3.5 网络（C2：只需逼近最优恢复参考）

- **输入 6 通道**：`fringe(1)` + `sin φ_dev,c` + `cos φ_dev,c` + `M_roi(1)` + `φ_ref mod 2π`（标定参考面相位的余弦/正弦，2 通道）；
- **载波口径（v2.5 修正）**：参考载波必须是**严格平面线性**的
  `φ̂_carrier = 2π(f̂_x u + f̂_y v)`（由观测域频谱主峰估计），**绝不能用二次面拟合**：
  二次面的 `Δφ̂ ≠ 0`，若 `h_input` 在 `ψ − φ̂_carrier` 上做调和延拓再加回，等价于把 `Δh = 0` 换成 `Δh = Δφ̂_carrier ≠ 0`，**直接破坏定理 1 的 `|Δψ| ≤ κ` 口径**，而且多连通域时二次拟合本身不稳定。
  平面载波的 `Δ ≡ 0`，故理论、证书、调和延拓全在总相位 `ψ` 上数学等价；网络通道里只用它做 `sin(ψ−φ̂_carrier), cos(ψ−φ̂_carrier)` 去载波归一 → **SynthFringe / MATLAB / 真实三源彻底统一**。
  观测到的瞬时频率 `f_inst = f₀ + ∂φ/∂x` 只用来**诊断类违反**，不进入网络输入；
- **粗相位 `φ_c`**：FTP 解调（观测域）→ 解包 → 域内 harmonic 填补。**纯物理前端，不用 GT**；
- **骨干**：4 级 depthwise-separable U-Net，base 32（2–4 M 参数）、**GroupNorm**（不用 BN）、无 x/y 通道；
- **输出与硬边界约束（v2.2 新增）**：

```
ψ_final(x) = h_input(x) + M_fix(x) · Δψ_net(x) ,
M_fix = smoothstep(t),  t = clip( dist(x, ∂Ω_clean) / w_blend , 0, 1 ) ,  w_blend ≈ 6 px
```

  - **`M_fix` 定义在 `Ω_roi \ Ω_clean` 上，不是只在盲区上**（v2.5 修正，堵死"降质区梯度被锁死"的漏洞）：
    `Ω_clean` = 严格干净的观测区（高调制、无饱和、离轮廓 ≥2 px）；`Ω_fix = Ω_roi \ Ω_clean` 同时包含**盲区 + 半影 + FTP 边缘畸变带 + 降质区（饱和/散焦/模糊/低调制）**。
    若像 v2.3 那样只在盲区设 `M_d`，则在"有观测但降质"的区域 `ψ_final ≡ h_input`，网络梯度恒为 0 —— 那部分**根本修不了**，而它正是"可修复类（Class P）"的主体。
  - `h_input` 的 Dirichlet 边界锚定在 **`∂Ω_clean`**（不是 `∂Ω_d`），这样同时解决了 FTP 边缘畸变（漏洞 1）；
  - **`M_fix` 必须用 C¹ smoothstep（三次多项式 `3t²−2t³`）**，不能用分段线性 clip：分段线性在 `t=0,1` 处二阶导数是两条 Dirac 线，`Δψ_final` 里 `ΔM_fix·Δψ` 与 `2∇M_fix·∇(Δψ)` 会在混合带两侧炸出局部曲率尖峰，三角测量后在点云法向上表现为一圈异常光照环；
  - **推理时 `Ω_clean` 必须由单帧前端自估**（调制 + 饱和 + 轮廓腐蚀），不许用 GT mask；
  - `L_smooth` 只作用在 `M_fix` 内部，**不许跨混合带**；
  - **代价必须写进论文**：锚点退到 `∂Ω_clean`（退 `d_edge` px）会把证书里的扭转函数从 `‖v_{Ω_d}‖` 换成 `‖v_{Ω_d ⊕ B(d_edge)}‖`。对一条 `w=11 px` 的细条阴影，两边各退 5 px → 有效宽度 21 px → `‖v‖ ∝ w²` 膨胀 **(21/11)² = 3.64×**，Tier-1 认证率会崩。所以 `d_edge` 必须压到 1–2 px（见漏洞 8 的 Masked 解调方案）；
- **辅助输出**：`log σ`、`Â`、`B̂`、三分类 logits、证书掩码 `ρ̂≤1`；
- **损失**：`L = L_phase + 0.5 L_fc + 0.1 L_nll + 0.2 L_cls + 0.05 L_smooth`
  - `L_phase`：`Ω_d` 内 SmoothL1（权重 ×2）+ `Ω_roi\Ω_d` 内权重 ×1（**不许改好区**）；
  - `L_fc = || M_obs ⊙ ( I − clip(Â + B̂ cos ψ, 0, 1) ) ||₁`（前向一致性，只在观测域；**必须带 clip**）；
  - `L_nll`：异方差高斯；`L_cls`：三分类交叉熵（标签来自 ρ）；`L_smooth`：边缘感知 TV（只作用在 `M_d` 内，避免把边界拉坏）；
- **分辨率自适应**：全卷积 + pad 到 32 倍数 + GroupNorm + **训练时 0.6–1.6× 随机缩放**（等价于条纹密度增广）；测试在 256²、384²、480×640 三档各报一次，掉点 >2% 触发重训；
- **训练**：AdamW 2e-4、batch 16、130 epoch、cosine、5 seeds；三阶段（只 `Δψ` 30 ep → 加 `L_fc` 40 ep → 加 `σ`+分类 60 ep）；hard split 与普通样本 1:1。

### 3.6 校准与风险控制（C3/C4/C5）

- **两级 conformal（v2.2 修正，替换"场景级"的含糊说法）**：
  校准单元 = **场景**；但分数必须先是**场景级标量**，否则退回像素级 conformal。定义

```
S_i = Quantile_{1−β}( { |φ̂(x) − φ(x)| / σ̂(x) : x ∈ Ω_d,i } )      （场景内 1−β 分位）
τ_c = 第 ⌈(n_c+1)(1−α)⌉ 个的 S_i                                    （每个 ρ 类各自取）
```

  给出的保证是**两级**的：

```
P_场景( 新场景中至少 (1−β) 的死区像素被覆盖 ) ≥ 1 − α .
```

  即"α 管跨场景、β 管场景内"。论文里必须这样写，**不能写"场景级 conformal + 像素级分数"**（那是像素级 conformal，且忽略像素相关性）。基线与消融里都要有 β 的扫描。
- **RCPS（v2.2 修正）**：`R(λ) = P(|Δφ|>φ_tol | σ̂≤λ)` 的**分母是随机的**，`R̂(λ)` 不保证单调，二分搜索会震荡。改为：
  1. `λ` 只取**固定网格**（如 200 个分位点）；
  2. 用 **self-normalized（WSR）上界**：`U(λ) = (E(λ)+Δ_n)/(A(λ)−Δ_n)`，`Δ_n = √(log(1/δ)/(2n))`；
  3. 对 `U(λ)` 取**running minimum**（沿 λ 递减方向），恢复单调性；
  4. 在网格上选最大的 `λ` 使 `U(λ) ≤ α`，并给出 `P(R(λ̂)>α) ≤ δ` 的 Bentkus 二项界。
  消融里报"经验 `R̂(λ)` 是否非单调"（预期会），用来说明为何不能用朴素二分。
- **深度传播**：`z = Π(φ)`（标定 + 三角测量），`σ_z ≈ |∂z/∂φ|·σ_φ`；报 mm 区间与 PICP。**覆盖率对 `W_p` 的尺度不敏感**（估计与区间同尺度），只有宽度与 RMSE 依赖 `W_p` → `W_p` 单独做敏感性表。
- **为什么不用 evidential**：旧实现的 `ν≤10, α≤10, β≤1` 硬 clamp 把"模型不知道"压到 ≤10%，死区恰是最需要大 epistemic 的地方 → evidential 只作基线。

### 4.6 规模、划分、验收

- **训练 12,000 = SynthFringe 6,000 + MATLAB 6,000（50/50）**；**真实数据 0 进训练**。
  - SynthFringe 6,000：4 密度 × 退化组合，**按场景划分**（注意：零件库会跨场景重复，见下方泄漏声明）；
  - MATLAB 6,000：从 10,000 个相位里 band-limit 后取，**按物体 ID 划分**（含 `_scale` 同组）；退化用 Synthetic-Cutout + 物理退化。
- **为什么必须两个都用（实测依据）**：SynthFringe 是同一批机械零件（齿轮/轴/方块/圆柱）的随机摆位，每场景 1–10 个连通域，面积 22.7%–54.0%、bbox 254–594 px；**摆位多样但形状族单一**，单独训练会诱导形状先验（PhiCalNet 2026 的诊断）。MATLAB 的 1 万个相位提供完全不同的曲面族与受控 κ 扫描，两者互补。

## 5. 实验设计（5 组 + 10 项消融）

**A. 证书有效性（理论）**
误差 vs `ρ`；**被认证比例按形状分**（细条 / **弧形** / 圆盘 / 十字 / L 形）；**soundness 检查**（认证样本中超容差的比例——必须给 **Clopper–Pearson 上界**，N≥1000，见 §10.3）；违反类（台阶/孤岛/**贯穿型**）时的失效分析；`κ̂` 敏感度（偏小 10%/20% 的违例率）；**边界阈值扫描**（`∂Ω` 定在 `CRB ≤ φ_tol/4·{0.5,1,2,4}` → 报 `δ_g` 与 `‖v‖` 的权衡曲线）。

**A2. 三组反例的正式实验（v2.2 新增）**
① **弯曲死区**：弧形/香蕉形阴影，报 `w_min²/8` 与扭转界的差距（已实测 275×），证明闭式界必须用 `d_eq`/`r_ins`/PDE 而非凸包宽度；② **贯穿型死区**：人为注入 `2πk` 偏移，报失效率（已实测 k≥1 即失效）；③ **边界噪声**：扫 `δ_g`，验证推论 3（`κ‖v‖+δ_g`）。

**B. 最优恢复参考逼近（C2）**
Identity、BM3D+DnCNN+FTP、**相位修补**（harmonic / Navier–Stokes / Telea）、深度图像修补（Partial-Conv / LaMa）、Ours、**ORR**、**ORR_noisy**。指标：mask RMSE、相对 ORR 的比值、`gain over ORR`（若低于 1 则说明半影带携带信息，需排除 GT 泄漏）。

**C. 校准（C3）**
reliability diagram、PICP vs α（α=0.05/0.1/0.2，全局与类条件）、区间宽、ECE/NLL、AURC/AUSE。
**基线必须包含 PhiCalNet 式做法**：① **像素级 split conformal**（无场景分组、无 Mondrian、无 RCPS）——用数字证明像素级校准在空间强相关死区上覆盖不足；② **top-5% 不确定性拒绝**（PhiCalNet 的拒绝策略），与 RCPS 的有限样本风险界对比；③ 另加 evidential(old)、MC-dropout、Deep Ensemble、HSURE 式异方差。

**D. 风险控制（C4）**
risk-coverage 曲线；接受集失败率与接受率；δ=0.05；换退化类型 / 换 `T` / 换分辨率；**接受集的形状构成**（细条是否更容易被接受——它们应该更容易）。

**E. 真实与 OOD（C5）**
11 个真实场景逐个报；受控孔洞扫 `w_eff` 与长宽比（真实 GT 上的相变支线）；跨传感器（4 个条纹密度）；合成→真实的覆盖掉点；背景泄漏率。**明确写清真实数据无标定 → 只报相位级，mm 只在标定基准上。**

**F. 跨源泛化（v2.4 新增，回答"是否只会形状先验"）**
`训 MATLAB → 测 SynthFringe`、`训 SynthFringe → 测 MATLAB`、`联合训练` 三种设定，各报：证书认证率（与网络无关）、相对 ORR 比值、类条件 PICP。
- 若跨源掉点 ≤5% → 模型学的是边界信息，主张成立；
- 若掉点大 → 说明存在形状先验，则把"**证书是物理量、不依赖网络**"提到摘要，网络降为可选组件（这与本文的护城河一致）。

**消融（10 项，按算力分两类）**

| 类 | 项 | 成本 |
|---|---|---|
| **零重训**（推理即可） | 去 Mondrian、去 RCPS、像素级 vs 场景级校准、去 `ρ` 门控、`κ̂` 估计方式（SG vs 局部二次）、`Ω_roi` 给定 vs 单帧估计 | 每项 <10 min |

## 17. 范围裁定：mm 降级为可选（2026-11-16）

**裁定**：D3–D4 的绝对 mm 几何**冻结**，主线回到相位域。

**理由**：题目 2 的四个贡献（证书 / 三分类 / 两级 conformal / RCPS 判决）**全部只依赖相位**。唯一需要投影仪-相机几何的只有主表的 **3D RMSE（mm）** 一列，而它不是任何一个贡献的载体。
D3–D4 实测状态：两套外参约定（`X_p = R X_c + t` 与 `X_c = R X_p + t`）都能给出 100% FOV 覆盖与 26k–30k px 的大平面片（中位残差 0.037–0.060 mm），但放大率反推与 `t_p` 语义不自洽，**无法唯一化**；继续攻是纯几何工程，与本课题的核心命题无关。

**替代方案**：

| 主表列 | 现在怎么写 |
|---|---|
| `Δφ`（rad） | 照常（主指标） |
| `Δz_equiv`（µm） | 用**标称灵敏度** `∂z/∂φ = p·Z/(2π·B)` 换算，表注写 **nominal, not calibrated** |
