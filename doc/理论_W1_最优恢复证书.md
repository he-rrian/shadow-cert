## 0. 记号与假设

- `Ω ⊂ R²`：死区（无调制光区域），有界、连通、Lipschitz 边界；`Ω̄ = Ω ∪ ∂Ω`。
- 表面类：`K_κ = { ψ ∈ C²(Ω) ∩ C(Ω̄) : |Δψ(x)| ≤ κ, x ∈ Ω }`，`κ ≥ 0` 已知或待估。
  **`κ` 是像平面（`u,v` 像素坐标）上的表观相位光滑性上界，量纲 `rad/pixel²`**；它随透视与物面倾角变化，**不是三维物理曲率**（见 §12-6）。
- 边界观测：`ψ|∂Ω = g`；实测为 `ĝ = g + ε`，`‖ε‖_∞ ≤ δ_g`（含噪声时用 §5bis）。
- `h`：`g` 的**调和延拓**（`Δh = 0` in `Ω`，`h|∂Ω = g`），存在唯一（`Ω` 正则、`g` 连续）。
- `v_Ω`：**圣维南扭转函数**，`−Δv_Ω = 1` in `Ω`，`v_Ω|∂Ω = 0`；`v_Ω ≥ 0`（极值原理）。
- `φ_tol`：测量容差（rad）。`ρ := κ‖v_Ω‖_∞/φ_tol`。
- **拓扑前提**（引理 3）：`Ω_roi \ Ω` 连通、`∂Ω` 为单一闭环；否则整周期阶数不可解，证书不适用。

> 记法：`‖·‖_∞` 指 `sup_{x∈Ω}`。`Δ` 为拉普拉斯算子。所有不等式在 `Ω` 内逐点成立（`C²` 下取 a.e. 即可）。

## 1. 引理 1（比较引理：逐点界）

**引理 1.** 设 `ψ ∈ K_κ` 且 `ψ|∂Ω = g`，`h` 为 `g` 的调和延拓。则

```
|ψ(x) − h(x)| ≤ κ v_Ω(x) ,    ∀x ∈ Ω.                                  (1)
```

**证明.** 令 `u = ψ − h`。则 `u|∂Ω = 0`，且 `Δu = Δψ`（`Δh = 0`），故 `|Δu| ≤ κ`。
定义 `U_± = κv_Ω ∓ u`。由 `−Δv_Ω = 1` 得 `ΔU_± = −κ ∓ Δu`，于是

```
ΔU_± = −κ ∓ Δu ≤ −κ + |Δu| ≤ 0 ,
U_±|∂Ω = κ·0 ∓ 0 = 0 .
```

`ΔU_± ≤ 0` 意味着 `U_±` **超调和**（superharmonic），由极值原理其最小值在 `∂Ω` 取到，即 `U_± ≥ 0` 于 `Ω`。两边同时给出 `u ≤ κv_Ω` 与 `−u ≤ κv_Ω`，即 (1)。∎

**说明.** 引理 1 只用了 `|Δu| ≤ κ` 与 `u|∂Ω = 0`，对**任意形状**的 `Ω` 都成立。这是全文的理论基座。

---

## 2. 定理 1（最优恢复：上界、minimax 下界、可达）

**定理 1.** 在引理 1 的条件下：

1. **上界**：`‖ψ − h‖_∞ ≤ κ‖v_Ω‖_∞`；
2. **minimax 下界**：设 `T` 为任意估计器（把边界数据 `g` 映射为 `Ω` 内的相位场），则

```
sup_{ψ ∈ K_κ, ψ|∂Ω=g}  |T(g)(x) − ψ(x)|  ≥  κ v_Ω(x) ,   ∀x ∈ Ω,
```

故 `sup_x` 之后仍有 `≥ κ‖v_Ω‖_∞`；
3. **可达**：`ψ_± := h ± κv_Ω` 是极值面，且 `‖ψ_± − h‖_∞ = κ‖v_Ω‖_∞`。

因此 `h` 是类 `K_κ` 上的 **minimax 最优**估计，最小最大误差恰为 `κ‖v_Ω‖_∞`。

**证明.**
(1) 直接由引理 1 取 `sup`。
(2) 注意 `ψ_± = h ± κv_Ω` 同时属于 `K_κ`（`Δψ_± = 0 ± κ(−1) = ∓κ`，`|Δψ_±| = κ`）且共享同一 `g`。给定 `x`，任一估计器对两者输出同一个值 `T(g)(x)`（因为边界数据相同），故

```
max{ |T(g)(x) − ψ_+(x)|, |T(g)(x) − ψ_−(x)| } ≥ ½·|ψ_+(x) − ψ_−(x)| = κ v_Ω(x).
```

对 `ψ` 取 `sup` 即得。对 `x` 取 `sup` 后右边为 `κ‖v_Ω‖_∞`。
(3) 由 (1) 取等号即见 `ψ_±` 达到上界。∎

**推论 1（证书）.** 若 `κ‖v_Ω‖_∞ ≤ φ_tol`，则**每一个** `ψ ∈ K_κ` 都满足 `‖ψ − h‖_∞ ≤ φ_tol`。
若 `κ‖v_Ω‖_∞ > φ_tol`，则存在两个与观测相容的表面，其在 `v_Ω` 取最大处的差为 `2κ‖v_Ω‖_∞ > 2φ_tol`。

> **这是本文与"给个不确定度热图"的根本区别**：推论 1 是一个**无分布、无训练、概率 1** 的陈述，而且它的否定（第二句）是**不可能性**。

## 3. 定理 2（圆盘：显式常数）

**定理 2.** `Ω = B_R`（半径 `R = d/2`）时 `v_Ω(x) = (R² − |x−x_c|²)/4`，`‖v_Ω‖_∞ = R²/4 = d²/16`。

**证明.** `Δ(R² − r²) = −4`，故 `Δ[(R²−r²)/4] = −1`；边界处 `r=R` 时为 0。∎

**数值核验.** `probes/theory_c1.py`：`w(0)` 与 `κR²/2`（直径）之比 = 1.0000。

## 4. 定理 3（Talenti：等面积圆盘上界）

**定理 3.** 设 `Ω*` 是与 `Ω` 等面积的圆盘（`d_eq := 2√(|Ω|/π)`）。则 `‖v_Ω‖_∞ ≤ ‖v_{Ω*}‖_∞ = d_eq²/16`。

**证明.** Talenti 的比较定理：把 `v_Ω` 作对称递减重排 `v_Ω#`，则 `v_Ω#` 满足 `−Δv_Ω# ≤ 1` 于 `Ω*`、`v_Ω#|∂Ω* = 0`，从而 `v_Ω# ≤ v_{Ω*}`。重排保持 `L∞` 范数吗？——不保持范数本身，但保持**水平集测度**：`|{v_Ω > t}| = |{v_Ω# > t}|`，而 `v_{Ω*}` 的球对称性给出 `v_{Ω*}(r) > t ⟺ r < r(t)`，于是 `{v_Ω# > t} ⊆ Ω*` 的等测度球 → `v_Ω# ≤ v_{Ω*}` 逐点。取 `sup` 得 `‖v_Ω‖_∞ ≤ ‖v_{Ω*}‖_∞|`。最后由定理 2 得 `d_eq²/16`。∎

**用途**：给出**闭式、O(1)** 的 sound 上界（只需面积）。**代价**：对细长/弯曲/环状形状极松（见下）。

> ⚠️ **Talenti 在环形/多孔死区上同样"面积虚胖"**（实测，`w1b_stress.py`）：
>
> | 形状 | 面积 | `‖v‖` | `d_eq²/16` | 松弛倍数 |
> |---|---|---|---|---|
> | 环 `R=100/90`（壁厚 10） | 5970 | 15.07 | 487 | **32×** |
> | 环 `R=50/40` | 2827 | 15.00 | 233 | 15.5× |
> | 环 `R=40/30` | 2199 | 14.97 | 183 | 12.2× |
>
> Talenti 只保证 **soundness**（对任意拓扑成立），不保证**紧**：重排保持面积，而环的面积随外径虚增，真实扭转只由壁厚决定（`≈w²/8`，实测 15.07 与 `(w+1)²/8 = 15.1` 完全一致）。
> **论文写法**：一句封死——"Talenti rearrangement preserves area and guarantees soundness across all topologies, but it also suffers area-inflation on annular or perforated shadows; closed-form formulas are therefore coarse screens only, and exact certification uses the sparse PDE solution of `‖v_Ω‖_∞`."

**数值核验.** `probes/theory_c1.py` 等面积序列：圆 1.02、方 0.96、椭圆 2:1 0.83、4:1 0.43、8:1 0.22、16:1 0.15（以 `d_eq²/16` 归一）——单调下降，验证 Talenti 与"细长则更松"。

## 5. 定理 4（条带界）与它在弯曲死区上的失效

**定义（最小条带宽度）**：`w_min(Ω) := min_θ ( extent of Ω along θ )`，即包含 `Ω` 的最窄条带的宽度（凸包宽度，旋转卡壳 O(n) 可算）。

**定理 4（条带界）.** 若 `Ω` 含于宽 `w` 的条带，则 `‖v_Ω‖_∞ ≤ w²/8`；对 `w×L` 矩形，`‖v_Ω‖_∞ ↑ w²/8`（`L/w → ∞`，指数速率）。

**证明.** 设最窄方向为 `y`，`Ω ⊆ S = {|y| ≤ w/2}`。取 `u_s(y) = (w² − 4y²)/8`，则 `−Δu_s = 1` 于 `S`，`u_s(±w/2)=0`。令 `W = v_Ω − u_s|_Ω`：`−ΔW = 0` 于 `Ω`（调和），`W|∂Ω = −u_s ≤ 0`。调和函数最大值在边界 → `W ≤ 0` → `v_Ω ≤ u_s ≤ w²/8`。∎

> ⚠️ **定理 4 只在"凸/直条带"意义上紧，对弯曲死区会灾难性失效。**
> 实测（`probes/w1b_stress.py` T1，15 种形状）：一条 10 px 厚、半径 100 px 的**弧形（香蕉形）阴影**，真实 `‖v_Ω‖_∞ = 15.07`，而凸包宽度 `w_min ≈ 182`，`w_min²/8 = 4140`——**松了 275 倍**；L 形 78 倍、十字形 57 倍。
> 界是 sound 的，但**没有任何判别力**：所有弯曲阴影都会被判"不可恢复"。
> **因此：`w_min²/8` 只能用于凸域/直条带的快速筛查；一切计算与论文结论都用精确的 `‖v_Ω‖_∞`（PDE 解）。** 论文里"宽度律"的措辞必须改成"**扭转宽度**"，不能写成"凸包宽度"。

**推论 2（可用的闭式兜底）**：

```
‖v_Ω‖_∞ ≤ min( d_eq²/16 ,  (r_ins + h)²/2 )      h = 网格步长（离散约定，见 §10.1）
```

其中 `r_ins` 为内切圆半径（最大距离变换）。

- `d_eq²/16`：**定理 3（Talenti）保证，严格可证**；
- `(r_ins+h)²/2`：对细长/弯曲形状**紧得多**（实测：细条 18.0 vs 15.0 = 1.2×；香蕉 20.4 vs 15.07 = 1.36×），但**目前只是数值猜想**（`‖v‖∞ ≤ ½r_ins²` 的连续版本尚未证出；对无限长条带取等号，故常数 `½` 是锐的）。论文里必须标成 *conjecture, verified on N shapes*，不能当定理论。
- `w_min²/8`：只在凸/条带情形加入 `min`。

**数值核验.** `probes/w1b_stress.py` T1：15/15 三个界都 sound；`w_min²/8` 在弯曲形状上松 57–275×；`r_ins` 界全部 sound 且紧。

## 5bis. 边界噪声：摄动引理

**引理 2（摄动引理）.** 设实测边界 `ĝ = g + ε`，`‖ε‖_{L∞(∂Ω)} ≤ δ_g`，`ĥ`、`h` 分别为 `ĝ`、`g` 的调和延拓。则

```
‖ĥ − h‖_{L∞(Ω)} ≤ δ_g .                                              (2)
```

**证明.** `ĥ − h` 调和，在 `∂Ω` 上等于 `ε`，由极值原理其 `L∞` 范数不超过边界上的 `L∞` 范数。∎

**推论 3（带噪证书）**：

```
‖ψ − ĥ‖_∞  ≤  κ‖v_Ω‖_∞ + δ_g  ≤  φ_tol  ⟺  certified .
```

**实测**（T2，`δ_g` = 0.02…0.5）：`‖ĥ−h‖_∞/δ_g` = 0.59–0.68 → 引理 2 成立，且调和延拓对边界噪声平均掉约 40%。

**工程含义（必须写进 Method）**：`∂Ω` 的取法是一个**两难**：
- 取在 `m≈0` 处 → `δ_g` 大（相位方差 ∝ σ²/B² 爆炸），且可能含跳周；
- 向外退到 `m≥0.3` → `Ω` 变宽，`κ‖v_Ω‖_∞` 随宽度**平方**增长。

**协议**：把 `∂Ω` 定在 `CRB ≤ φ_tol/4` 的等值线上（即 `δ_g ≤ φ_tol/4`），并在补充材料里扫这条阈值，给出"`δ_g` 与 `‖v‖` 的权衡曲线"——这本身就是一张有说服力的图。

## 5ter. 拓扑与完整边界前提（贯穿型、贴边型）

**引理 3（适用前提）.** 推论 3 成立需同时满足：

1. **连通性**：`Ω_roi \ Ω_d` 连通、`∂Ω_d` 为单一闭环（单帧相位可绕 `Ω_d` 一致解包）；
2. **完整边界**：`∂Ω_d ∩ ∂Ω_roi = ∅`（死区完全被观测域包围，Dirichlet 数据处处存在）。

**为什么第 2 条不可省（反例）**：若 `∂Ω_d` 有一段贴着 `∂Ω_roi`（free-edge shadow），该段没有观测、只能改 Neumann `∂_n h = 0`。取 `ψ₁ ≡ 0` 与 `ψ₂ = c·x`（朝自由边单调倾斜的平面），两者在**有观测的那段边界上完全一致**，且 `Δψ_{1,2} ≡ 0 ≤ κ`，但自由边处的误差随 `c → ∞` 任意大。
→ **贴边死区在 `K_κ` 类下是单侧外推，minimax 误差无界**，证书不成立（除非额外假设 `|∇ψ| ≤ M`，那会把类改掉）。

**处理**：把 `∂Ω_d ∩ ∂Ω_roi ≠ ∅` 的死区（free-edge shadow）**强制归入 Class U / Tier-2**，不发放 Tier-1 证书；`h_input` 在该边上仅用 Neumann `∂_n h = 0` 作启发式基底，由网络 + conformal 兜底。
这在论文里同时立住一条清晰物理边界：**内闭孔（Dirichlet，由二阶曲率 `κ` 控）vs 贴边孔（外推，无界，只能走统计风险）**。

**实测**（T3，薄横带 3.3%，人为给下半区加 `2πk`）：

| k | 实测最大误差 | 模型界 `κ‖v‖` |
|---|---|---|
| 0 | 0.10 rad | 2.23 rad |
| 1 | **5.83 rad** | 2.23 rad |
| 2 | **11.63 rad** | 2.23 rad |
| 3 | **17.42 rad** | 2.23 rad |

→ 误差随 `k` 线性增长（每 `2πk` 约 5.8 rad），而模型界几乎不变 → **证书失效**。
**处理**：把贯穿型/贴边型作为**类违反**单列（数据里显式构造，实验结果里报失效率），并声明此类区域只给相对相位，绝对阶数需第二次曝光或双频。

## 6. 定理 5（C¹ 修正：1/ln2）

**设定**：除边界值 `g` 外还观测到法向导数 `g₁ = ∂_n ψ|∂Ω`（半影带可估）。

**定理 5.** `Ω = B_R` 时，两个共享 `(g, g₁)` 的可行表面之差 `w` 满足 `w|∂Ω = ∂_n w|∂Ω = 0`、`|Δw| ≤ 2κ`，且

```
max|w(0)| = κ R² ln2 / 2 = κ d² ln2 / 8 ,
```

即证书半径由 `κd²/16` 收紧为 `κd² ln2/16 = κd²/23.08`，**收紧因子 `1/ln2 = 1.4427`**。

**证明（径向极值）.** 令 `f = Δw`。极值取 `f = −2κ`（`r<ρ`）、`+2κ`（`r>ρ`）。由 `(r w')' = r f` 积分得

```
w'(r) = κ(r² − 2ρ²)/r  (r>ρ),   w'(r) = −κr  (r<ρ).
```

`∂_n w|∂Ω = w'(R) = 0 ⟹ ρ = R/√2`。再积分并令 `w(R) = 0` 得

```
w(0) = κ R² [ ¼ − ½ln2 + ¼ ] = κ R² ln2 / 2 .
```

∎

**数值核验.** `probes/theory_c1.py`：`w(0)/(κR²ln2/2) = 1.0001`，`w'(R) = −2.6e−3 ≈ 0`，`ρ/R = 0.7071 = 1/√2`。

> **重要更正**：本方案的 v2 初稿曾写"C¹ 可收紧 4 倍"，**错误**。在 `|Δψ| ≤ κ` 类下 `1/ln2` 是可达的精确上界，**不可能有 4×**。提升认证率的主渠道是定理 4（宽度），不是定理 5。

## 7. 定理 6（不可能性：negative result）

**定理 6.** 若 `κ‖v_Ω‖_∞ > φ_tol`，则**不存在**任何只依赖 `g` 的估计器能在 `K_κ` 上保证容差 `φ_tol`。

**证明.** 由定理 1(2)，任一估计器在 `x* = argmax v_Ω` 处的最坏误差 `≥ κ‖v_Ω‖_∞ > φ_tol`。∎

**意义**：这条定理把"为什么再大的网络也不够"变成一句可证的话，也把 Tier-2（校准风险）从"补丁"变成"必然"。

## 8. 统计修正：`κ̂` 的校准与"置信证书"

定理 1–6 都以 `κ` 为**已知的类参数**。实际中 `κ` 只能从**观测域**估计，因此证书是**条件性**的。两种口径都要写进论文：

**(a) 条件证书（概率 1）**：若 `κ̂ ≥ sup_Ω|Δψ|`，则推论 1 成立。这是**确定性的**，不含概率。

**(b) 置信证书（概率 1−ε）**：把安全系数 `γ ≥ 1` 引入 `κ̂ = γ·Q_q(|Δφ̂_SG|)`（`Q_q` 为观测环带上的 `q` 分位，`Δφ̂_SG` 先经 Savitzky–Golay 或局部二次拟合正则化，抑制二阶差分对噪声的放大）。在校准集上取

```
γ* = min{ γ :  #{certified & violated} / #{certified}  ≤  ε } ,
```

报告 `γ*`、违例率、以及**保守代价**（认证比例随 `γ` 的下降）。这样证书从"类条件"升级为"有限样本统计意义下的 sound"，与 Tier-2 的 conformal 语言一致。

> 论文写法：**定理 1–6 给 (a)；§8 给 (b)，并把 `γ*` 与违例率放表**。审稿人问"`κ̂` 怎么估"时，(a)+(b) 一起答。

## 9. 算法：`‖v_Ω‖_∞` 的计算

| 方法 | 公式 | 复杂度 | 用途 |
|---|---|---|---|
| **精确** | 稀疏求解 `−Δv = 1, v|∂Ω = 0`（每个连通域一次，5 点差分，仅在其 bbox 内） | `O(A log A)` | 数据生成 + 推理（256²、数个连通域 → 单帧 <50 ms） |
| **闭式上界** | `min(d_eq²/16, w_min²/8)` | `O(n)` | 快速筛查、论文中的解析表达 |
| **扭转宽度** | `w_eff := √(8‖v_Ω‖_∞)`（定义式，量纲 px） | 同上 | 与条纹周期归一：`w_eff/T` |

**证书判据（最终形式）**：

```
ρ = κ · ‖v_Ω‖_∞ / φ_tol  ≤ 1    ⟺    certified
等价写法：   κ · w_eff²/(8 φ_tol) ≤ 1
```

### 10.3 统计功效：N 必须 ≥ 1000（对评审 2.3 的回应）

V8 的 66 个 case 里，γ=1 时认证 17% ≈ **11 个认证样本，零违例**。按 Clopper–Pearson，真实违例率的 95% 上界是

```
1 − 0.05^(1/11) = 1 − 0.762 = 23.8% .
```

**所以"零违例"在统计上是空的。** 必须做到的规模：

| 认证样本数 n | 0 违例时的 95% 上界 |
|---|---|
| 11（现在） | 23.8% |
| 100 | 2.95% |
| 300 | 1.0% |
| **1000** | **0.30%** |
| 3000 | 0.10% |

**行动**：W3–W4 用生成器批量跑 **≥3000 个死区连通域**，报告 `n_cert`、违例数、Wilson/Clopper–Pearson 区间。在此之前，图表里只写"pilot (n=11)"，不许写"零违例"。

### 10.1 离散约定（必须写进补充材料）

离散求解时 Dirichlet 数据落在**网格外一层的像素中心**，故有效域比像素集宽一个像素：

```
有效尺寸 = (像素 extent) + 2          # 亦即 w_eff = 内部宽度 + 1
d_eq,eff = d_eq + 1
```

**不采用此约定会假报"定理被违反"**：细条 `w=8` 时 `‖v‖_离散 = 10.00`，而按 `w=8` 算的界只有 `8`；按有效宽度 `9` 算的界是 `10.125`，正好 sound。V7b 的 strip 系列（0.959→0.9989）逐点验证了这条约定。

### 10.2 `κ̂` 的实测结论（对评审第 2 条的回应）

`w1_verify.py` V8（66 个 case：11 个相位 × 3 个孔径 × 2 种形状）：

- `κ̂_SG / κ_true`：**P10 = 0.35**，P50 = 1.42，P90 = 1.96 → **环带上的 SG 估计在 10% 的情况下低估 3 倍**。评审的担心完全成立：低估即失去 soundness。
- `γ` 扫描（`φ_tol = π/10`）：

| γ | 认证比例 | 认证中违例率 |
|---|---|---|
| 0.5 | 36% | **16.7%**（不 sound） |
| 1.0 | 17% | **0.0%** |
| 1.5 | 15% | 0.0% |
| 2.0 | 14% | 0.0% |

- 参考：全体 case 中 `err > φ_tol` 的比例为 **56.1%**，而 γ=1 时只认证 17% → 证书**保守但 sound**，剩下的 39% 由 Tier-2 承担。

## 12. 适用边界（必须写进 Discussion）

1. **类假设**：`|Δψ| ≤ κ`。台阶/孤岛处 `Δψ` 是 δ 函数 → 类被违反 → 证书不适用（实测 `mesa=2π` 时 2π 失败 95%，见 `physics.py`）。论文必须给出这一类违反下的失效分析。
2. **`κ̂` 的上界性**：`κ̂` 低估即证书失效。必须报 (b) 口径的违例率，且样本量 ≥1000（§10.3）。
3. **边界噪声**：`δ_g` 必须进证书（推论 3）；边界取法本身是个两难（§5bis），要给权衡曲线。
4. **拓扑**：贯穿型死区（`Ω_roi\Ω` 不连通）整周期阶数不可解 → 证书不适用（§5ter，实测 17.4 rad 误差 vs 2.23 rad 界）。**必须在数据里显式构造并单列失效率。**
5. **多连通/带孔**：`Ω` 非单连通时 `v_Ω` 仍在、引理 1 仍成立；但闭式界只能用 `d_eq` 与 `r_ins`，**不能用 `w_min`**（凸包宽度会爆）。
6. **`κ` 的坐标依赖性**：`κ` 是像平面量（rad/px²），随透视放大与物面倾角增大。**物面与光轴夹角 >60° 时表观 `κ` 会被透视压缩放大**，证书保守性自然增加——这句要写进 Discussion，并在实验里报一个倾角敏感性。
7. **`Ω` 的未知性**：`Ω` 要从单帧推断（§3.1 三个域），其误判会传播——单列消融。
8. **`r_ins` 界是猜想**：`‖v‖∞ ≤ ½r_ins²` 连续版本未证（条带取等号，常数锐），只作闭式兜底并标注 *conjecture*；一切数值用 PDE 精确解。
