## 2. 8→64 定不住的机制（已证实）

若某连通域落在 `ψ_1` 的 ±π 分支另一侧，`Φ_1` 就带一个 `2πm` 误差，而它在前两级**完全隐身**：

```
1→3:  3·2πm     = 6πm   ≡ 0 (mod 2π)   → 残差为 0
3→8:  (8/3)·6πm = 16πm  ≡ 0 (mod 2π)   → 残差为 0
8→64: 7.6·16πm  = 121.6πm → −0.4πm     → m=1 时 1.26 rad；m=2 时 2.51 rad
```

实测 `P50`：`01200` = **2.49 rad**（m=2）、`02399` = 1.58、`00000` = 0.14（m=0）——**与公式一致**。

## 7. D3–D4 进展（2026-11-16）：几何已修，约定仍待唯一化

### 7.1 修掉一个会导致全盘错误的符号 bug

光线-平面求交的平面方程里，法向常数写反了一个负号（`D = (u−cx)·t_z − fx·t_x` 被我写成了 `(u−cx)·r3 − fx·r1` 的同号组合），导致 `z` 整体反号。**症状**：`coord`（相位推的投影仪列）为负，而重建点重投影到投影仪却有 100% 落在视场内 —— 这两个量本应相等，矛盾暴露了 bug。
修正后，**所有一致解都落在 `axis = u`**（符合"竖条纹→投影仪列"的物理预期），修复前却全是 `axis = v`。

### 7.2 判据从"中位残差"换成"最大平面片面积"

中位数 / P5 局部平面残差对**任何光滑场**都趋近 0，无法区分"正确重建"与"被 `u_p0` 掰弯的光滑曲面"。改用**最大连通平面片面积**（局部 25×25 平面拟合残差 < 0.1 mm）：

| conv | axis | sign | u_p0 | 最大平面片 | 中位残差 | Z50 | FOV 覆盖 |
|---|---|---|---|---|---|---|---|
| **B** | u | −1 | 684 | **29,924 px** | 0.060 mm | **165 mm** | 100% |
| **A** | u | −1 | 0 | **26,197 px** | **0.037 mm** | **271 mm** | 100% |
| B | u | +1 | 684 | 5,214 | 0.246 | 44 | 67% |
| A | u | +1 | 0 | 863 | 0.571 | 355 | 96% |

两个强候选：
- **A**：`X_p = R X_c + t`（投影仪在相机前方 145.6 mm）、`u_p0 = 0`（图案自然原点）、Z50 = 271 mm；
- **B**：`X_c = R X_p + t`（投影仪在相机后方 145.6 mm）、`u_p0 = 684`、Z50 = 165 mm。

两者都过 `PV < 0.1 mm`（中位 0.037 / 0.060 mm）与 100% FOV 覆盖，**尚不能唯一判定**。

### 7.3 一个尚未解决的量纲线索

由"相机条纹周期 10 px / 投影仪周期 15 px"得放大率 `m = 0.667`。另一方面 `m ≈ (f_c/f_p)·(Z_p/Z) = 0.863·(Z_p/Z)` → 需 `Z_p/Z = 0.773`。
- 约定 A 下 `Z_p = Z − 145.6` → 反解 `Z ≈ 641 mm`（实测 271）；
- 约定 B 下 `Z_p = Z + 145.6` → `Z_p/Z = 1.88`（实测比值在 A 为 0.46）。
两条都不自洽 ⇒ **`t_p` 的语义或符号仍有偏差**，这是判定 A/B 的最强线索，下一步优先解决。

## 3. 阻塞点：`8_6 → 64_15` 为什么定不住

已排除的假设：

| 假设 | 检验 | 结果 |
|---|---|---|
| 四套条纹不是同一场景 | mask IoU（0.99+）、调制图相关（0.75–0.99） | **排除**，同一场景同一位姿 |
| 步长 / 阶次 bug | 见 §2 | **已修** |
| `8_6` 是 6 步 40° 的异常序列 | 拟合步长 59.2° | **排除**（标签正确） |
| 名义比 8 可直接用 | 8.0 处浓度 0.198 / 7.60 处 0.891 | **排除**，必须用实测比 |
| `64_15` 是二值离焦（非正弦） | 时域谐波 `h3/h1 = 0.028`、`h2/h1 = 0.049` | **排除**，基本是纯正弦 |
| 噪声来自低调制区 | 把 ROI 收紧到 `mod > 0.5·P90` | **未解决**，`frac>π/2` 仍 0.9%–90% |

仍然存在的现象：**逐块局部比值在 7.11–7.80 之间波动（±5%）**，即 `Φ_64` 与 `Φ_8` 不是逐点线性关系。用"比值场"替代常数比值**更差**（场估计本身噪声大，`frac>π/2` 反而升到 13–27%）。

三条候选解释（尚未判定）：
1. **局部比值估计被噪声污染**：`ψ_64` 的相位噪声 ~0.02 rad → 局部梯度噪声 ~0.03 rad/px，占局部梯度的 5%，正好等于观测到的漂移幅度。若为此，则全局常数比应能工作，问题出在我的 `a` 估计精度（0.8% 误差 × Φ_8 跨度 28.8 rad = 0.23 rad，不足以解释 P50=2.5 rad 的场景）；
2. **`64_15` 的相位存在随局部条纹周期变化的空间偏置**（采样/积分效应）：局部周期实测在 8.4–10.7 px 之间变化，若有采样偏置，其大小随周期变化，正好产生空间变化的表观比值；
3. **某些场景（如 01200，ROI 72%）本身就异常**，把统计拖坏。
