## 3. 关键决定与理由

| 决定 | 理由 | 被否决选项 |
|---|---|---|
| **公平单帧档为主门禁** | 部署只有单帧 + 前端，Oracle 吃 GT dead/无纹理误差，不可达 | 用 Oracle 当主门禁（会把 C2 逼成刷上界） |
| **Oracle 只作参考** | 5seed 总体 1.537×，物理上界；按用户 2026-11-18 决定不硬刷 | 把 Oracle 1.54× 当失败项 |
| **5 seeds，seed 4 为代表** | 公平档 5/5；seed4 最优但门禁看 5seed 均值/最差 | 只报最好 seed |
| **100 epoch，30/30/40** | 全局 cosine，stage3 最佳 | 60 epoch 旧排期（已废弃） |
| **cut 不参与 phase loss** | cut 的 2π 活塞单帧不可解，属 Class U | 强行让网络拟合 cut |
| **edge/degraded 降权 0.2** | 边界/退化低调制，非主目标 | 等权（会拖累 P 类） |
| **SF 只作 G5-b 误差评测** | SF 严格证书 5%/10% 无解；γ=.20 只是 20% 工作点 | 把 SF 当第二训练域 |

## 7. 陷阱清单（最值钱）

1. **“4/4”是旧数**：seed4 完成后是 **5/5**；README 已改，旧文档若写 4/4 以本文件为准。
2. **公平档 ≠ Oracle 档**：Ours/Biharm_SF≈0.273 是主结果；Ours/Biharm_oracle≈1.537 是参考，不要混。
3. **门禁方向**：Ours/Biharm **≤** 0.95；不要写成“≥”。
4. **`last.pth` ≠ `best_stage3.pth`**：seed0 的 best 是 stage3 last；其余用 best_stage3；不要拿 last 当最佳。
5. **compact 的 float16 会翻 boundary**：seed4 P 类 compact 0.9312 vs full 0.9365（差 1 scene）；C3 主表必须 full 官方重算。
6. **P-only 全拒不是“P 不可用”**：是 n=193 下 WSR/EB 加性项 ~4.7–5.6% 吃光预算；先 Bentkus/CP，再下结论。
7. **U 不能池进 RCPS**：pooled 70.6% 是诊断，不是证书接受率；U 在推理前拒绝。
8. **α_eff 是 post-hoc**：看了 test 才挑的，不能当主 G6。
9. **本地 torch 坏**：不要试图本地跑模型；用服务器或重装。
10. **full 缓存在服务器**：本地只有 compact 和 seed0 的 3 个 full 文件；关机未释放，开机先下载。
