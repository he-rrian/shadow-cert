## 1. 我实测到的 7 条与文档冲突的事实

> 全部可复现：`python p2_work/probe*.py`。数字都是中位数，来自 10–200 个对象。

### F1（P0）数据渲染不物理：86.5% 的相位对象无法用单帧载波表示

文档 §3.1 要求"保持原始绝对相位（min=0，不做归一化）"、`f0` 固定。实测：

- `original_phase` 的局部相位梯度（换算成 cycles/px）：P50 **0.108**、P90 0.233、逐对象 P99 中位 **0.245**、最大 0.85；
- **86.5% 的对象 P99 梯度 > f0 = 1/16**（0.0625）；large（max>150）档 100%、medium 档 94% 违规；
- 直接按 `cos(2πf₀x + φ)` 渲染，**即使一点退化都不加**，用经典 FTP+解包复原：

| 载波 | 干净条纹上的 RMSE 中位 | band-limit 后 |
|---|---|---|
| 1/16 | **20.6 rad** | 0.20 rad |
| 1/8 | **13.0 rad** | 0.16 rad |
| 1/6 | **7.8 rad** | 0.14 rad |

单个对象看更直观：max=110 → RMSE 31 rad / 2π 失败 70%；max=190 → RMSE 64 rad / 失败 70%。

**后果**：如果按文档生成，"死区内的 2π 失败"里有一大半来自**载波混叠**，而不是死区。审稿人（光学背景）一眼能看出条纹被斜率压没了，全文的核心命题当场作废。
**根因**：这个坑 P1 已经踩过——`1\dataset\generate_fringe_dataset_from_scaled.m` 第 295–296 行 `carrier + phi`，正是同一个写法。这几乎可以解释 P1 论文里的 "Large Fail 42.5%"：不是网络不行，是数据不物理。

### F2（P0）"阴影 / 散焦 / 运动模糊 / 低调制 / 饱和"大部分**不是死区**，只是降质

这是我这次复核最重要的发现，它直接改写了论文的物理骨架：

- **乘性阴影**（`I = A_amb + R·Rs·(a + b cos)`）：Rs 只缩幅度、**不改相位**；
- **散焦 / 运动模糊**：低通，只降调制度；
- **sensor 饱和（clipping）**：无记忆非线性，**基波相位不变**（只长大三次谐波 + 幅度损失）。
- 实测：把饱和区做到占 **1%–27%**，Identity 的 2π 失败率仍只有 **0.000–0.020**；把阴影做到 `m<0.08`（占 0.5%–4%），也一样。

**只有"完全没有调制光"（遮挡 / 全黑 / 相机看不到投影光）才真的毁相位**：同一批对象、同样的面积，Identity 的 2π 失败率 **4%→81%**（面积 1%→40%）。
**建议**：把 7 类退化拆成两族——**"降质（信息还在，可修复）"**与**"盲区（信息没了，只能靠边界，几何受限）"**。这不是文字游戏，它正好给出 §4-M1 的两条界各管一段的物理依据，也回答了"为什么需要两个下界"这个审稿人一定会问的问题。

### F3（P0）G0 门禁与"每样本死区 2%–30%"自相矛盾

`2%` 覆盖率对应单孔等效直径 **≈41 px**；而 G0 要求"2π 失败 >25%"，实测要到 **3% 覆盖率（d≈49 px）才 29%**。也就是说：覆盖率在 2%–3% 之间的样本必然不达标，却又满足规格。**规格必须按 `d_eq` 分层，而不是只按覆盖率分层**（10% 的覆盖率可以是 20 个小孔——很容易；也可以是一个 60 px 的大孔——很难，两者的"可恢复性"完全不同）。

### F4（P0）6 个真实场景的"死区"是画上去的，而且 GT 近平面

| 项 | 文档写的 | 实测 |
|---|---|---|
| 死区来源 | 真实物理退化 | `single_shot*.png` 被 `add_occlusion()` 覆盖成**纯黑矩形**（mask 内像素 100% 等于 0），面积 8.5%–11.5% |
| 真实物理降质 | — | 饱和 0%–3.1%；fringe 可见度 <0.04 仅 0%–4.5% |
| GT | "169–211 rad" | 跨度 170–210 rad 对，但**近平面**（25–32 个周期，起伏很小），4 步 PSP + skimage 解包 |
| GT 质量 | — | 无 NaN；但有 **0.06%–2.1%** 像素 `|∇gt|>π`（解包撕裂），必须剔除或计入 GT 噪声 |
| 标定 | "3D RMSE 标定后必须报" | **全树 0 个标定文件**；raw 是 1706×1279 JPEG，proc 是中心裁 1169→256 |

**后果**：这 6 个场景在真死区下几乎是平凡任务（近平面 + 平面拟合就能补），支撑不起"真实金属高光件/阴影台阶"的叙事。

### F5（P1）ρ 的两个下界现在都不能用

- **几何界**：`κd²/8` 是**一维**外推的最坏界。实测（二维闭孔，harmonic 延拓为包络）比值 `κd²/8 ÷ 包络RMSE` = **4.4–9.0，中位 7.6**。按 `κd²/8` 判，ρ 会几乎处处 ≥1 → 全部"不可恢复" → 接受集为空，风险控制失效。
  → **建议改成二维常数（实测落在 `κd²/64` 附近），并在数据生成时把这条界当"标签"验证，而不是拍脑袋取 `ρ_c`**。
- **信息界**：死区**内**按定义没有调制，σ_CRB→∞，ρ 恒 ≥1，同样退化。
  → 建议 σ_CRB 只在"降质族"里定义（截断/谐波污染模型），"盲区族"交给几何界，两族分工。

### F6（P1）单帧"绝对相位"是口径问题，必须在方法/摘要里写死

单帧只能定到**全局 piston**以内。实测就是靠 `median(err[~mask])` 对齐。文档 §4.6 提了一句，但摘要与主表会撞枪。**建议主表同时报"对齐后（piston-aligned）"与"绝对（无对齐）"两列**——成本极低，而且是个差异点（几乎没有论文这么报）。

### F7（P1）算力与现实不匹配

本机：**RTX 4060 Laptop 8 GB**，`torch / h5py / sklearn` **都没装**。文档要 20k 样本 × 150 epoch × 5 seeds ≈ 200–400 GPU·h → 这台机器要跑 2–3 周，W5–W6 必然爆。F: 剩 85 GB（20k × 786 KB ≈ 16 GB 够用）。

## 4. 五处必须改的地方（按优先级）

### M1（P0）理论：ρ 从"两个下界取 max"改成"可行集宽度 + 两族分工"

保留你的核心洞察（可恢复性由两条界决定），但换掉会自我退化的写法：

- **信息界**只用于**降质族**（截断/谐波/低调制）：用截断正弦模型的 CRB（不是普通 CRB），得到"部分可观测"的误差下界 `σ_info`；
- **几何界**只用于**盲区族**：给二维闭孔的界（常数取 `κd²/16`（最大）/`κd²/64`（均方），用实测校核，不要用一维的 `/8`），得到 `e_geo`；
- **ρ 定义为"可行解集合的半宽 ÷ 容差"**：`ρ = |{φ 与观测及先验相容}| / (2φ_allow)`，两条界分别是这个集合的两种收紧方式。这样 ρ 有物理意义、可计算、且不会恒为 ∞；
- **覆盖用 Mondrian conformal**（按 ρ 类分组校准）：给的是**类条件覆盖**，比全局覆盖更符合"我接受了这个点，误差多大"的计量语义；`ρ` 的标签来自物理量（m、边界距离、κ、噪声），**不来自误差**，所以不循环；
- **RCPS** 选接受阈值：`P(|Δφ|>φ_tol | accepted) ≤ α`。

> 这一改把"论文的定理"从"两条教科书界的 max"变成"集合辨识 + 条件覆盖"，是 Q1 与 Q2 的分界线；也是唯一能让 ρ 真正"有用"的写法。

### M2（P0）数据：把退化重新分成两族，并加物理合法性门

见 §5 的完整规格。要点：**盲区族（无调制光）占 45%，降质族占 40%，复合 15%**；每个样本过 band-limit 门；mask 由 CRB 反推。

### M3（P0）指标：主指标换掉

| 现在的主指标 | 问题 | 换成 |
|---|---|---|
| mask 内 2π 失效率（25%→5%） | 在合法数据上天然 4%–81%，且随覆盖率单调，不是方法差异 | **容差失败率** `P(|Δφ|>φ_tol)`（φ_tol 取 π/10 与 π/2 两档）+ **接受集失败率**（RCPS） |
| mask RMSE 降 ≥50% | 对 Identity 成立（-93%），但对**真实对手**只有 -7.7% | **与边界信息包络的差距**（目标 ≤15%）+ **接受集 RMSE** |
| PICP@90 | 保留 | 保留，但加**类条件 PICP**（Mondrian）与**区间宽** |

2π 失败率仍报，但作为**辅表**（它随覆盖率变化，正好是 Fig.2 的纵轴）。

### M4（P1）真实数据：把黑矩形降级，把物理 mask 提上来

- 6 场景：从 4 步 `capture_1..4` 算**物理可见度**与饱和，重建真死区 mask（实测只有 0–4.5%，说明这 6 个场景**没有**真死区 → 只能当"低死区"对照）；
- **黑矩形不要扔**：它是"受控孔洞"，恰好可以在**真实 GT** 上扫 `d`，直接给 Fig.2 的真实支线（我实测这个用法很干净）；
- GT 撕裂像素（0.06%–2.1%）剔除并在表注写清；
- 补采 10–20 个场景：金属高光、深阴影、台阶/孤岛、运动。**这是 G3 能否成立的关键**；
- 标定：raw 还在（1706×1279），可以做 Zhang + 投影仪标定 → mm。

### M5（P1）算力：3 seeds 迭代 + 5 seeds 主表，或云 GPU

模型压到 2–3 M 参数、256²、batch 8 + AMP；数据从 20k 降到 **12k**；主表 5 seeds 只在最后跑一遍（或租 1 张 A100 跑 3–4 天）。同时 `pip install torch h5py scikit-learn`。

## 5. 数据处理方案（v2 规格，确认后我就按这个执行）

### 5.1 目录与产物

```
F:\paper\p2_data\            # 不放 C:\，F: 剩 85 GB 够
  shards\ shard_0000.h5 ...   # 12 片，每片 ~0.9 GB
  real\                       # 6+ 场景的物理 mask / GT 清洗结果
  cards\DATA_CARD.md          # 数据卡（发布用）
  cards\SPLIT.json            # 物体级划分 + 哈希
scripts\                      # 生成器/校验器（进 git）
```

### 5.2 Stage 0：物理合法性门（这是文档里完全没有的一步）

```
for each object:  φ_dev ← fai（float32，min 平移不做归一化）
  g = |∇φ_dev| / 2π
  # 选载波：从 {1/16, 1/12, 1/8, 1/6} 里挑使 s_band ≥ 0.5 的最大 f0
  s = min(1, 0.45 · f0 / P99.9(g))            # 0.45 留分析带余量
  φ_dev ← s · φ_dev
  通过条件：  P99.9(|∇φ_dev|/2π) ≤ 0.45·f0   且   min f_inst ≥ 0.25·f0
             f_inst = f0 + ∂φ_dev/∂x / 2π
  记录 s, f0, g_max；s<0.10 的对象降权（占比控制在 10% 以内）
```
验收：干净的 band-limited 条纹，`FTP+unwrap` 在**无退化区**上 `2π` 失败 <0.5%、RMSE<0.5 rad（我实测 0.14–0.20 rad，达标）。

### 5.3 Stage 1：三类对象族（决定基准有没有"相变"）

| 族 | 占比 | 做法 | 对应物理 |
|---|---|---|---|
| **A 平滑** | 50% | 直接用 `original_phase`（band-limited） | 坡度受限的普通零件；信息受限 |
| **B 台阶/孤岛** | 30% | 把相位切片后整体加 `Δh·2π`（Δh∈{0.5,1,1.5,2,3}），或用 mask 抠出孤岛 | 台阶、焊缝、孤岛 → **真 2π 歧义**（实测 mesa=2π 时 2π 失败 95%） |
| **C 多物体/遮挡** | 20% | 两张相位图拼画布，各自不同偏移 | 真实相互遮挡、阴影边界 |

> 为什么必须这样：单靠 smooth 对象，`2π` 失败只有 4%–15%（d<50），根本没有"不可恢复"这一类；B 族的台阶一加，2π 失败直接到 90%+，ρ 的"不可恢复类"才有样本。

### 5.4 Stage 2：退化算子（按物理顺序，标注"是否毁相位"）

| 算子 | 参数 | 是否毁相位 | mask 判据 |
|---|---|---|---|
| **遮挡/全黑**（主力） | 软半影 2–6 px + 内部无调制；面积 1.5%–30% | **是**（实测 2π 失败 4→81%） | `可见度 < 0.03` |
| 饱和 clipping | 高光斑 1–3，幅度 0.2–0.8；bloom σ 2–8 | **否**（基波保相位，只加谐波） | `I ≥ 0.98` 记为"降质"不是"盲区" |
| 阴影（乘性） | `Rs=1−a·exp(−d²/2σ²)`，a 0.5–0.95，σ 10–40 | 否（只降 SNR） | `R·Rs·b < 3σ_noise` |
| 散焦 | PSF σ 0.5–2.5 | 否 | 局部 `b` 衰减 >60% |
| 运动模糊 | 核长 1–10 px | 否 | 局部对比度 <0.10 |
| 低调制 | `b←b·α`，α 0.02–0.3，σ 20–60 | 否（低于噪声才毁） | `m<0.08` |
| 镜面 | 加性高斯高光 σ 3–15 | 否（若饱和则同上） | `I≥0.98` |
| γ / 噪声 | γ 0.95–1.05，σ 0.004–0.02 | 否 | — |

**硬规则**：每个死区必须带 **≥6 px 半影带**（`m<0.3`）。没有半影带，经典相位修补就等于最优，网络没有存在空间（实测：相位修补距包络仅 7.7%）。

### 5.5 Stage 3：mask 由物理量反推，per-pixel 存"ρ 的原料"

不要存死标签，存原料（ρ 的定义以后一定会改，原料不能重生成）：

```
mask      uint8   bit0 observed / bit1 blind / bit2 degraded-sat
                  / bit3 missing-penumbra / bit4 blur / bit5 multi-object
mod       float16 局部调制度 m
crb       float16 σ_CRB（截断模型）
dbound    uint16  到死区边界的距离 ×2（存 0.5 px 精度）
kappa     float16 局部 |∇²φ|（GT 上算，用于几何界）
noise     float16 估计噪声 σ
```
`ρ` 与三分类在分析脚本里算，**不写进数据**。

### 5.6 Stage 4：拒绝采样与分层（按 `d_eq`，不按覆盖率）

## 9. 决策选项与推荐（v1 新增）

### 9.1 三个包的区别

| | **包 A 最小改动** | **包 B 中等改动（推荐打底）** | **包 C 大改（推荐加冕）** |
|---|---|---|---|
| 数据 | M2（band-limit + 两族 + `d_eq` 分层） | M2 全部 + 包络标注 | 同 B |
| 主指标 | 仍用 2π 失败率 + RMSE | M3（容差失败率 / 包络差距 / 接受集风险 / PICP） | 同 B |
| ρ 与理论 | 保留 `max(σ_CRB/σ_allow, κd²/8/φ_allow)` | 几何界常数改二维（`κd²/16` 最大、`κd²/64` 均方）；**分类标签由"包络误差"生成**（不由 ρ 自生成，去循环）；conformal 改 **Mondrian（按 ρ 类分组）** | 把 §3.2 重写成**集合辨识**：ρ = 可行解集合半宽 ÷ 容差；给出二维界的推导 + 非唯一性（台阶/孤岛内含于盲区）的刻画 |
| 能拿到的数字 | 2π 失败率随覆盖率变化的一条曲线；三分类只剩两类 | 类条件 PICP、接受集风险/接受率、与包络的差距（目标 ≤15%）、OOD AUROC | 加：理论界 vs 实测包络的相关性（目标 Spearman>0.85）、可证伪的"不可恢复"预言 |
| 代价 | 0（只改生成器） | +5 天（指标与校准层） | +2–3 周（纯推导 + 验证） |
| 审稿人最可能的攻击 | "你的界凭什么是紧的"（答不上） | "两条界是教科书结论"（属方法学借用，可接受） | "推导太理论/实验支撑不足"（需数据兜底） |
| 结局预估 | OLEN 5 成 / TIM 1–2 成 | **OLEN 8 成 / TIM 3–4 成** | **TIM 5 成** / 推不出则退回 B |

**为什么 A 不行**（三个硬理由，都是实测）：
1. `κd²/8` 比实测包络保守 **4.4–9.0 倍** → ρ 几乎处处 ≥1 → 三分类退化为两类，"接受集"为空，RCPS 无意义；
2. 分类标签由 ρ 自己生成 → 用它评估分类 = 循环论证，审稿人一句话打死；
3. 2π 失败率在合法数据上是覆盖率的单调函数（1%→4%，30%→78%），**不能反映方法差异**，主表会变成一张"数据难度表"。

**为什么 B 够用**：B 把"界"从"证明"降级为"可校准的预测器"，再用 **Mondrian conformal** 给类条件覆盖——保证来自 conformal，不来自界。这样界只需要"单调 + 可计算"，不需要"紧"，审稿人打不动；而"类条件覆盖 + 接受集风险"是 TIM/OLEN 都认的计量语言。

**为什么把 C 单独拎出来**：C 是唯一能补上"没有 mm"这个缺口的写法（用理论深度换计量深度）。但它有 30% 概率推不出紧的二维界，所以**不要在 W1 就承诺 C**，而是设一个 **W6 抉择门**：若到 W6 时"二维界 vs 实测包络"的 Spearman>0.85 且常数在不同 `d`/`κ` 档稳定（斜率比 1.0±0.25），就补写 C 的理论章冲 TIM；否则按 B 投 OLEN。

| 类 | 占全幅 |
|---|---|
| 精确 0（真黑） | 38.0% |
| **噪声 1–4（背景也不是 0）** | **27.8%** |
| 边缘过渡 5–60 | 1.4% |
| 真实物体（≥60） | 32.8% |

→ 任何"调制度低 → 死区"的规则会把 **65.8%** 的画面判成死区。**必须**三掩码分开：

| 掩码 | 定义 | 用途 |
|---|---|---|
| `M_roi` | 有表面、该测 | 损失只在域内；域外不许改 |
| `M_dead` ⊆ `M_roi` | 有表面但条纹被毁 | **主指标只在这里算** |
| `M_bg` | 没有表面 | 不参与对错；单列"背景泄漏率" |

四条落地规则：
1. **数据**：用多帧最强值 `max≥25` 精确抠物体轮廓（渲染集唯一的"作弊优势"），`M_roi`/`M_bg` 存进分片；
2. **模型**：输入给 `M_roi` 通道，损失只在域内；
3. **评测**：新增一列**背景泄漏率**（背景上被预测为非零调制/被改动的比例）；
4. **消融**：`M_roi` 由单帧估计（调制度阈值 + 轮廓连续性）vs 给定，报指标差。

**且这是一条 contribution，不是补丁**：单帧里"被遮挡的暗表面"与"没有表面"物理不可区分 → 测量域在死区内部不可辨识 → 可恢复性必须**以测量域为条件**（正好嵌进包 C 的集合辨识）。Discussion 拟写：

> The measurement domain is itself unobservable inside a dead zone: a region that carries no modulated light is equally consistent with a shadowed surface and with no surface at all. The recoverability analysis is therefore conditional on a domain supplied by the fixture, by the previous frame, or by silhouette continuity, and we report the degradation of every metric when that domain is estimated from a single frame instead.

**规格修正**：死区覆盖率改为 `M_dead / M_roi ∈ [2%, 30%]`（原来按整幅算，`M_roi` 只占 33%，30% 会把整个物体吃掉）。

### 10.3 机制复核（重跑后更干净）

| 退化 | d=32→128 的 Identity 2π 失败 | Identity RMSE | 包络 RMSE |
|---|---|---|---|
| 饱和 clip | 0.000 → 0.018 | 0.34–0.98 rad | 0.19–2.16 rad |
| 阴影（乘性） | 0.000 → 0.000 | 0.27–0.40 rad | 0.15–0.43 rad |
| **全遮挡** | **0.105 → 0.699** | **2.06–33.1 rad** | **0.41–2.84 rad** |

→ 只有**全遮挡**造真死区；Identity 在 d=64 上比包络差 **16.4×**，方法的头寸极大（不是"只差 7.7%"——那是对**相位修补**而言，相位修补仍是最强对手，必须进主表）。
