## 0. 一句话结论

**S4 的主线成立：在 `phi_tol = pi/10`、`delta_g = 0.13` 下，取 `gamma* = 0.75`，val 认证 25.7%、test 25.2%，认证集内“逐像素 max 误差 > 证书界”的违例率仅 1.0% / 1.6%（95% CP 上界 3.2% / 4.1% < 5%）；严格 `gamma=1` 时 0/109、0/114 违例（CP 2.7% / 2.6%），`C_5pt_max` 最大 0.332 ≤ 1。** 但 W4 同时推翻了两条旧假设：

1. **ORR 不是全局最强基线**：Biharm 在 blob 上 `Rel-ORR = 0.389`，总体中位 0.876；ORR 只在 sliver 上最优（Biharm 1.527）。S5 的 `Rel-ORR <= 1.15` 门禁必须改。
2. **“部署态 40–50% 认证”不成立**：A-all（750 全体）口径的 `gamma*` 只有 14.5–17.6%，低于 20%；35–55% 只有在 20% 风险档（52.4%）或放宽容差到 `pi/5`（56.0%）才达到。主口径已改为 **`eps=0.05` 下 >= 20%**。

## 1. 口径与常量（冻结）

| 项 | 值 | 说明 |
|---|---|---|
| `phi_tol`（主） | **`pi/10 = 0.314159 rad`** | 5% 条纹周期；`pi/5`、`pi/20` 只进敏感性表 |
| `delta_g`（主） | **0.13 rad** | 探针 A 的 P95；0.02 / 0.05 只进敏感性 |
| `kappa_hat`（主） | **环带 P75**（`meta.kappa_hat_ps[1]`） | P90 敏感性用 `kappa_hat_ps[2]`，零返工 |
| `kappa_oracle` | **洞域内 P95**（`kappa_oracle`） | 只验定理；不部署 |
| `N_denominator`（A-all） | **750**（每个 split 含 `vinf` 的样本数） | 写成常量 `N_DENOM`，表注标明 |
| 违例分子 | **逐像素 `max abs(error)`** | 一律不用 mean；Per-sample 二值判定 |
| A-all（全局诊断） | `max_err > gamma*kappa_hat*vinf + delta_g`，分母 750 | 衡量 `kappa_hat` 的全局保守性 |
| A-cert（主口径） | 同上，分母 = `n_cert` | 证书只在认证集上发，条件违例率才是承诺 |
| B（部署承诺） | `n_cert` 内 `max_err > phi_tol` | “接受集失败率”，Tier-2 语言 |
| 置信上界 | 单侧 95% Clopper–Pearson | **n = 样本数，不是像素数** |
| `C_5pt_max` | `max abs(ORR-phi) / (max abs(Delta_5pt phi) * vinf)` | 在认证集上报；`<=1` 才定理层面 sound |

> 注：`n_cert` 在每个口径下都必须显式报出；`gamma` 越大认证集越小，违例率会“假性归零”。

## 5. 主校准：认证集 + 5% 风险（风险曲线）

`gamma* = 0.75`。分母为认证集；A-cert = `max_err > 证书界`；B = `max_err > phi_tol`；括号内为单侧 95% CP 上界。

| `eps` | `gamma*` | val 认证 | val A-cert | val B | test 认证 | test A-cert | test B |
|---|---|---|---|---|---|---|---|
| **0.05** | **0.75** | **25.7%**（193/750） | **1.04%**（CP 3.23%） | 0.52%（CP 2.43%） | **25.2%**（189/750） | **1.59%**（CP 4.05%） | 0.53%（CP 2.49%） |
| 0.10 | 0.60 | 34.1%（256/750） | 4.30%（CP 7.01%） | 2.73%（CP 5.07%） | 34.3%（257/750） | 5.84%（CP 8.85%） | 3.11%（CP 5.55%） |
| 0.20 | 0.40 | 52.4%（393/750） | 16.54%（CP 19.94%） | 10.94%（CP 13.88%） | 51.2%（384/750） | 17.97%（CP 21.50%） | 11.20%（CP 14.20%） |

**读法**：
- 5% 风险档（主）：val 25.7% → test 25.2%，跨 split 只差 0.5 个百分点；CP 上界 3.2% / 4.1% 均 < 5%。
- 10% 风险档：34.1% / 34.3%，CP 7.0% / 8.8% < 10%。
- 20% 风险档：52.4% / 51.2%，但 **test 的 CP 21.5% 略超 20%**；该档只作参考曲线，不作主承诺。
- `B` 始终低于 `A-cert`：`max_err > phi_tol` 比 `max_err > 证书界` 更难触发（证书界 <= phi_tol）。

**为什么主档取 0.75 而不是 0.65**：0.65 是 val 上 CP 最小的 5% 档（2.1%，CP 4.4%），但余量只有 0.6 个百分点；0.75 的 val CP 3.2%、test 4.1%，余量更大。**test 只做一次性验证，未按 test 回调 `gamma`。**

### 8.1 `delta_g`（A-cert，CP-safe 5% 重新校准）

| `delta_g` | `gamma*` | 认证率 | A-cert | CP95 | 备注 |
|---|---|---|---|---|---|
| **0.13（主）** | 0.65（主档用 0.75 留余量） | 31.3%（0.65）/ 25.7%（0.75） | 2.13% / 1.04% | 4.42 / 3.23% | — |

## 9. 关键发现与物理解释

### 9.1 为什么 Biharm 在细条上崩、在圆盘上赢（定理 1 vs 定理 5）

- **定理 1（minimax 最优）** 的类 `|Delta psi| <= kappa` 只约束二阶导；调和延拓是这一类上的 minimax 最优，**细条正是界最紧、极值面最容易逼近的情形**。所以 sliver 上 ORR = 1.000、Harmonic = 1.204，Biharm = 1.527。
- **定理 5（C¹ 只值 `1/ln2`）** 说明：如果额外假设 C¹（斜率连续），常数只能从 1 收紧到 1.4427，**并不能把最坏情形变好**。但 Biharm 解的是 `Delta^2 h = 0`，它把“斜率连续”当成硬约束：在**宽洞（blob）**里，真实曲面的斜率/曲率平滑，这个先验正好贴合，误差降到 ORR 的 0.389；在**窄缝（sliver）**里，四阶 Green 函数在两侧边界之间振荡，边界噪声被放大并过冲，误差反而到 ORR 的 1.527。
- 一句话给论文：**ORR 是“对最坏曲面最优”，Biharm 是“对光滑曲面最优”**；两者不是同一个“最强”，必须分形状报。这也解释了为什么网络要学“按形状选先验”，而不是死记一个插值核。

### 9.2 `kappa_hat` 的全局低估与认证集的自选择

`kappa_hat` 是环带 P75，洞内真实曲率（`kappa_oracle` P95）约为它的 2 倍。所以 A-all 在 `gamma=1` 时仍有 7.1% 样本超界；但**认证集恰好是 `kappa_hat*||v||` 最小的子集**，这些样本的真实误差也小，于是认证集内 0/109 超界。这不是矛盾，而是条件证书的本意：**只在能认证的样本上承诺**。论文必须同时报 A-all（诊断）和 A-cert（承诺），不能只挑一个。

### 9.3 点估计 vs 置信上界

`eps=0.10` 时 A-all 的点估计 `gamma* = 0.90`（9.2%），但 95% CP 上界 11.1% > 10%；CP-safe 要 `gamma=1.00`（7.07%，CP 8.80%）。**所有“<= eps”的表述都应带 CP 上界**，否则 750 个样本的点估计会被审稿人一击。

### 9.4 认证率目标的修订

原“35–55%”只有把风险预算放到 20%（52.4%）或把容差放宽到 `pi/5`（56.0%）才能达到；5% 风险档的真实值是 25.7%。主口径已改为 **`eps=0.05` 下 >= 20%**，35–55% 降为 `eps=0.10–0.20` 档的参考值。这一条已写入 `题目2_定义与实施前置.md`（2026-11-17 修订）。

## 12. 给 S5 的六条结论

1. **证书口径**：`gamma=0.75`，认证集 A-cert，5% 风险；`gamma=1` 作严格对照。推理时证书由 `kappa_hat`、`vinf`、`delta_g`、`phi_tol` 直接算，**不走网络分类头**。
2. **S5 门禁**：总体 `Ours/Biharm <= 0.95`；分形状 sliver `Ours/ORR <= 1.05`，arc/blob `Ours/Biharm <= 1.05`；`Rel-ORR <= 1.15` 只作参考列。三档退路见交接。
3. **辅助分类头**：按 `gamma=0.75` 动态重算 P 标签（P 占比 ~13%），逆频率加权 CE，`lambda_cls <= 0.1`，必须监控 **P-class recall/F1**（下限 0.5），不能只看总体准确率。
4. **形状先验**：sliver 上 ORR/调和最优，arc/blob 上 Biharm 最强；网络应学“按形状选先验”，而不是单一插值核。
5. **`delta_g` 不是瓶颈**：0.13→0.02 重新校准后认证率基本不变（25.7→26.8%）；不要再花时间压边界噪声。
6. **`phi_tol` 是主旋钮**：`pi/20` 6.3%、`pi/10` 25.7%、`pi/5` 56.0%；主口径守 `pi/10`，另两档只进敏感性表。
7. **SF 已导出并做过目标域重标定（S5 前置）**：SF-val 480 / SF-test 480，六族各 80；Tier-1 `gamma=1` **0/240 / 0/240**（`rho` P50 3.83 / 5.45）。在 SF-val 上重标定（零重训）：`pi/10` 下 **5% 与 10% 风险档均无解**；20% 档 `gamma=0.20` 得 val 42.5% / test 29.6%（test CP 22.7%，略超 20%）。**SF 只作 G5-b 误差评测；证书只报 MATLAB（C4 的 γ 域相关，见定义文档 v3.1 §4bis.4）。**
