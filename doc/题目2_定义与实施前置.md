## 一、题目 2 是什么

### 1.1 一句话

**从一张单帧条纹图出发，判定每个死区像素的相位能否被"证明地"恢复（给物理证书），对无法证明的部分给出有覆盖率保证的区间，并把两者合成一条风险受控的"接受/拒绝"测量判决。**

### 1.2 不是什么（主动排除，写进 Introduction）

| 不是 | 为什么排除 |
|---|---|
| 图像修复 / 去噪 / 超分 | 主指标不是 PSNR，是 mask 内相位误差 + 覆盖率 + 接受集风险 |
| "又一个不确定度网络" | 我们给**证书**（不依赖网络）与**覆盖保证**（可检验），不是相关性热图 |
| 多帧 / 双频 / 时序 | 输入严格一帧；多帧只作为"补拍"这个动作的讨论 |
| 边缘部署 / 加速 | 属于 P3；本文不碰 p99 延迟 |
| 3D 重建 / mm 精度 | **mm 冻结**（见 §5）：绝对几何需标定，与本课题四个贡献无关 |

### 1.3 科学问题

> 死区的相位误差，是否存在一个**只依赖可观测量**（局部调制度、死区几何、边界噪声）的**可计算上界**？若存在，它有多紧？若不存在（超出界），残差能否被**有限样本风险控制**兜住？

### 1.4 四个贡献与证据

| # | 主张（可证伪） | 证据 | 反例测试 |
|---|---|---|---|
| **C1 证书** | 对任意死区 `Ω`，`abs(ψ−h) ≤ κ‖v_Ω‖∞ + δ_g`（扭转函数 + 引理 2 边界噪声），故 **`ρ = (κ‖v_Ω‖∞ + δ_g)/φ_tol ≤ 1` ⟺ 被证明可恢复**；反向：`ρ > 1` 时**不存在**任何只依赖边界的估计器能保证容差 | 定理 1–6 + 引理 2 + 零违例（60/60、24/24、15/15） | 违反类（台阶、贯穿型、贴边型）→ 报失效率 |
| **C2 宽度律** | 可恢复性由**扭转宽度** `w_eff = √(8‖v‖∞)` 决定，**不是面积、也不是凸包宽度** | 细条 10×200 认证 100% vs 等面积圆盘 0%；香蕉形阴影凸包界松 275× | 换长宽比、换 κ |
| **C3 逼近 ORR** | 总体 `Ours/Biharm ≤ 0.95`；分形状 `Ours ≤ 1.05×min(ORR,Biharm)`（sliver 分母 ORR，arc/blob 分母 Biharm） | 与 Identity / 相位修补 / ORR / ORR_noisy / Biharm 对比 | 换条纹密度、跨源（MATLAB↔SynthFringe） |
| **C4 风险受控** | 两级 conformal：`P_场景(场景内覆盖率 ≥ 1−β) ≥ 1−α`；RCPS：`P(R(λ)>α) ≤ δ`；**`γ` 域相关，换域须目标域重标定**（见 §4bis.4） | PICP vs α；risk-coverage | 合成→真实、换退化类型、换分辨率 |

### 1.5 与 2026 对手的差异（一句话）

HSURE-CFPP 与 PhiCalNet 都在"给不确定度"；我们在"**判可证明性 + 给覆盖保证 + 做接受/拒绝**"，并且证书是**纯物理、与网络无关**的——这是本文唯一不可替代的护城河。

### 1.6 三分类（无遗漏的穷举划分）

```
R  = ¬blind ∧ (σ_info ≤ σ_allow)
P  = ¬R ∧ [ (blind_interior ∧ ρ ≤ 1) ∨ (¬blind ∧ σ_info ≤ σ_dead) ]
U  = 其余全部
     （含 blind_interior ∧ ρ > 1；贴边型/贯穿型死区；σ_info > σ_dead 的极重度降质区）
```

`blind_interior` = 死区且满足引理 3 的两条前提（`Ω_roi\Ω_d` 连通、`∂Ω_d ∩ ∂Ω_roi = ∅`）。
`ρ = (κ‖v_Ω‖∞ + δ_g)/φ_tol`（**含边界噪声项**，与 §1.4 的 C1 一致）。

## 三、正式实施前必须落定的 5 件事

### D1 探针 A：FTP 边缘畸变 `δ_g(d_edge)`（半天，纯相位域）

**要定的事**：① `Ω_clean` 的判据（调制阈值 + 饱和 + 轮廓腐蚀几 px）；② `M_fix` 的锚点位置；③ `d_edge` 能不能压到 1–2 px。

**做法**：在已解好 GT 的 10 个场景上注入 6 px 半影球遮挡，同场跑两条曲线：**标准 FTP** vs **Masked 局部正弦 LSQ**（窗口 5×5 / 7×7 / 9×9，在真实曲面 κ 上跑），画 `δ_g` vs 距遮挡边缘距离。

**为什么是前置**：`‖v‖ ∝ w²`，若 `d_edge = 5 px`，细条 `w=11→21 px` 使 `‖v‖` 膨胀 **3.64×**，Tier-1 认证率直接崩。这条曲线决定 W3 生成器的半影带宽度与 `M_fix` 定义。

### D2 探针 B：真实数据与泄漏（半天，纯相位域）

**要定的事**：① 11 个真实场景里实际有几个有**非平面**曲面（若多数是平板，真实支线失去区分度）；② `T_real` 分布（若真实条纹周期 25–35 px，现在 0.6–1.6× 的尺度增广覆盖不到）；③ SynthFringe 场景编号是否为"同一 CAD 模型旋转"序列（决定 train/test 分组 key）。

### D3 三个阈值常量（需你确认）

| 常量 | 含义 | 取值 | 影响 |
|---|---|---|---|
| `φ_tol` | 测量容差（主） | **π/10 = 0.314 rad**（已确认） | 直接决定 `ρ` 与 Tier-1 认证率 |
| `φ_tol` 副档 | 敏感度分析用 | **v3.1（W4 实测）**：`π/10` 唯一主口径；`π/20 / π/5 / π/2` 三档只进敏感性表（6.3% / 56.0% / 78.1% 认证），见 §4bis.3 | 副表 |
| `σ_allow` | 判 Class R 的上限 | `φ_tol/2`（≈95% 达标，已确认） | R/P 分界 |
| `σ_dead` | 判"不可观测"的上限 | `π/2`（已确认） | P/U 分界 |

> 这三个是**任务参数**，不是理论常数；论文里要列表并做敏感度。

### D4 mm 列的最终形态（已确认冻结）

**冻结绝对 mm。** 主表用 `Δz_equiv`（µm），固定标称换算系数：

```
Δz_equiv = k_nom · σ_φ ,   k_nom := p·Z₀/(2π·B) = 0.5 mm/rad   （nominal, not calibrated）
```

- `p`：条纹周期（mm）、`Z₀`：标称工作距、`B`：标称基线；三者只用于给出**量纲**，不声称标定；
- **PICP 在 `Δz_equiv` 上做，覆盖率与 `k_nom` 的取值无关**（估计与区间同尺度），这一句必须写进表注，堵住"尺度不变性"的挑刺；
- `k_nom` 取定后全文一致，不随场景变。

### D5 训练配比与泄漏声明（已确认）

6k SynthFringe + 6k MATLAB（50/50）；真实 11 场景**只测不训、不调参**；全文统一用"**未见过的场景/位姿**（unseen scenes / poses）"；**跨源泛化（MATLAB ↔ SynthFringe）升格为主实验组**（而非补充材料）。

## 四-bis、v3.1 修订：认证率、G5-a、φ_tol、C4 适用范围

> **保留 v3.0 原口径**：v3.0 预期“部署态 Tier-1 认证率 40–50%，落在 35–55% 目标内”（`交接_S3到S4` §0.0），当时的假设是 blob 占 1/3、γ=1.0 偏保守。W4 实测推翻了这一预期；本节保留原值、修订理由与被否决项。

### 4bis.1 认证率目标（35–55% → `eps=0.05` 下 ≥20%）

**v3.0**：35–55%。**v3.1 主口径**：`eps=0.05`（认证集内“逐像素 max 误差 > 证书界”）下 **≥20%**；实测 `gamma*=0.75` 时 val **25.7%** / test **25.2%**，认证集内超界 1.04% / 1.59%（95% CP 上界 3.23% / 4.05%）。

**参考档**：`eps=0.10` 下 **34.1%**（`gamma=0.60`）、`eps=0.20` 下 **52.4%**（`gamma=0.40`）。35–55% 只有把风险预算放到 20%（52.4%）或把容差放宽到 `pi/5`（56.0%）才达到；作为 5% 风险档的目标不成立。

**CP 合法性（v3.2，指令 2）**：`eps=0.20` 的 MATLAB test A-cert 为 **17.97%，CP95 = 21.50% > 20%**，该档只作**点估计参考，CP 不合法**；CP 合法的只有 **`eps=0.05`（val 3.23% / test 4.05%）** 与 **`eps=0.10`（val 7.01% / test 8.85%）** 两档。引用 52.4% / 51.2% 时必须同时写这句。

**为什么不是射箭画靶**：v3.0 §六本来就写了“Tier-1 认证率 <20% → 降级”这条线；25.7% 过的是原线。35–55% 是 W3 阶段的期望分布，其“blob 占 1/3、γ=1 保守”的前提被 W4 直接测量修正——属于标准的“假设被测量修正”，修订记录留痕即可。

**被否决**：继续追 35–55%（只能靠 20% 风险档或 `pi/5`，与“5% 风险证书”的定位不符）；A-all 主口径（17.6% <20%，且把未认证区混进条件违例率）。

### 4bis.2 S5 门禁 G5-a（`Rel-ORR ≤1.15` → 分形状最强基线）

**v3.0**：`Rel-ORR ≤1.15`。**v3.1**：
- 总体：`Ours / Biharm ≤ 0.95`；
- 分形状：`Ours ≤ 1.05 × min(ORR, Biharm)`，即 **sliver 分母用 ORR、arc/blob 分母用 Biharm**；
- `Rel-ORR` 只作参考列，不再单独作为门禁。

**依据**：Biharm 总体中位 `Rel-ORR=0.876`，强于 ORR 的 1.000；sliver 上 ORR 0.093 vs Biharm 0.122（Biharm 1.527×），arc/blob 上 Biharm 分别 0.988× / 0.389× ORR。若沿用 1.15，网络可以比 Biharm 差 31% 仍“通过”。

**退路**：sliver `≤1.05` 全套主张；`1.05–1.15` 退为“sliver 匹配 ORR、arc/blob 显著优于 Biharm”；`>1.15` 承认细条纯几何已近最优、增益集中宽洞。详见 `交接_S4到S5` §6.3。

### 4bis.3 φ_tol 副档（三档敏感性，主口径不变）

**v3.0**：π/20 或 π/5 待定，另留 π/2 作防跳周对照。**v3.1**：`π/10` 仍是**唯一主口径**；以下只进敏感性表（W4 实测，val，A-cert CP-safe 5% 重校准）：

| 档 | 容差（rad） | `γ` | 认证率 | A-cert | CP95 |
|---|---|---|---|---|---|
| `π/20` | 0.157 | 0.20 | 6.3% | 0/47 | 6.19% |
| **`π/10`（主）** | **0.314** | **0.75** | **25.7%** | **1.04%** | **3.23%** |
| `π/5` | 0.628 | 0.95 | 56.0% | 2.86% | 4.59% |
| `π/2` | 1.571 | 1.30 | 78.1% | 2.90% | 4.32% |

**结论**：认证率随容差单调上升；`π/5`、`π/2` 只用于展示缩放规律，**不得**升为并列主口径（TIM 会质疑“放宽主容差刷认证率”）。

### 4bis.4 C4 的适用范围（新增，最重要）

C4 的“证书 sound”是**模型无关**的：定理本身不依赖域，换域后只要用该域的 `kappa_hat`、`vinf`、`delta_g` 重算，证书仍然成立。**但 `gamma` 是域相关参数**，换域必须用目标域校准集重标定；未重标定前，**不得**声称跨域覆盖率或认证率。

**SF 实测（v3.2，2026-11-17 唯一场景扩样后）**：
- 数据：SF-val **450** / SF-test **450** 个含 vinf 样本，每族 150，**全部唯一场景**（无重复）；γ=1 时 **0/450、0/450**（sound 但零覆盖）。
- 严格协议（每个 ε 各自在 SF-val 上选 γ，test 一次性）：`eps=0.05` **无解**（n_cert≥50 下最好 CP 6.4% @ γ=0.35）；`eps=0.10` 的 γ=0.20 在 val CP 8.6%、test CP **15.3%**（>10%，test 不合法）；`eps=0.20` 的 γ=0.10 在 val CP 17.9%、test CP **26.4%**（不合法）。
- 唯一 CP 合法的 SF-test **20%** 证书来自**保守口径 γ=0.20**（val 的 ε=0.10 工作点）：162/450 认证（36.0%），A-cert 10.5%，CP **15.3%**；分族 sliver 104/150 CP 18.0%、arc 58/150 CP 17.3%、blob **0/150**。**但 test block 15 的 CP 为 32.3%（9/45）>20%**，所以 20% 只能写成 pooled/分族保证，**不能**写成 block 条件保证。
- `n_cert≥180` 与 `CP≤20%` 在 SF-test 上**不可同时满足**：γ=0.17 → 183 认证 / CP 20.4%；γ=0.18 → 177 认证 / CP 18.5%。不要为过门禁回调 γ。
- 违例归因（γ=0.10，test 60 个 A 违例）：**oracle 37（62%）、bound_only 23（38%）、boundary 0**；主因是 CAD 锐边使洞内真实 κ 超出环带 κ̂（光滑类假设被触发），不是 `delta_g` 边界噪声。
- 因此：**SF 只作 G5-b 零样本误差评测**；论文不得写“SF 上证书覆盖 X%”。C4 的“跨域”应表述为“证书形式跨域；参数须目标域校准；SF 的 5%/10% 无跨 split 证书，20% 只在保守 γ 下 pooled/分族成立且 block 15 不成立”。

## 五、不做什么（防止再次跑偏）

1. **不再碰绝对 mm 几何**（外参语义、`t_p` 反解、光线-平面求交的绝对深度）；
2. **不再扩充理论**（定理 1–6 + 引理 2/3 已冻结，除非探针发现反例）；
3. **不追新数据集**（三源已定）；
4. **不做边缘部署、不做多帧、不做双频**；
5. **不在真实数据上调参**（只测）。
