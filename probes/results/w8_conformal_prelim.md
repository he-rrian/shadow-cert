## 1. 口径

```
S_i = Quantile_{1−β}( |ψ−φ| / σ̂ )   （场景内，GT-dead 像素）
τ_c = 第 ceil((n_c+1)(1−α)) 个 S_i    （Mondrian: P/U/R 各自）
success_i = 场景内被覆盖的 dead 像素比例 ≥ 1−β
G6: P_scene(success) ≥ 1−α
```

- **β 是“允许的未覆盖率”**：β=0.05/0.10/0.20 → 目标场景内覆盖率 95%/90%/80%。
- α 是跨场景失败率目标：0.05/0.10/0.20。
- `σ̂ = exp(0.5·logσ)`（模型输出的是 log variance）。
- R 类（degraded）**没有 dead 像素**，所以 R 的 conformal 阈值是空的；P/U 两类可分。

**观察：**

1. **场景级 conformal 明显优于像素级**：α=0.05、β=0.05 时全局 0.941 vs 像素级 0.712；α=0.10 时 0.877 vs 0.488。像素级把空间相关的像素当独立样本，覆盖率严重虚高不足，这正好是 W8 要证明的。
2. **当前协议下 G6 没有全过**：α=0.05、β=0.05 只差 0.9%；α=0.10/0.20 系统性低 2–5%。
3. **不是 τ 算错**：τ 是标准 split-conformal 分位；低覆盖更可能来自 **val/test 的 block/DTD 域偏移**（val block 12–14，test block 15–17；DTD 类目也不同），以及 **val 同时用于选 best checkpoint** 的轻度选择偏差。
4. 用固定 epoch 100 的 `last.pth` 代替 `best_stage3`，结果几乎一样（α=0.05 全局 0.941），所以主因不是 checkpoint 选择。

## 3. 需要你决定的问题

1. **β 的口径**：我按“β = 未覆盖率，目标覆盖率 = 1−β”实现（β=0.05/0.10/0.20 → 95/90/80%）。如果你原意是“β = 覆盖率”，网格要反过来。**请确认。**
2. **val/test 域偏移下的 G6 口径**：
   - A. 如实报“未完全达标”，保留当前 τ（科学上最干净）；
   - B. 用 **保守校准**（在 val 上按 α_eff=α−δ 取 τ，δ 由 block 方差/CP 下界定），用区间变宽换覆盖达标；
   - C. 扩大校准集或重训 3-way split（train/cal/test），成本高；
   - D. 把 G6 改成“经验覆盖 + CP 下界 + 块异质性”三项并列，不强行 ≥1−α。
3. **RCPS 的风险单元**：方案写 `R(λ)=P(|Δφ|>φ_tol | σ≤λ)`（像素风险），但 `n=场景数`。我建议：
   - 主指标：**像素池化风险 + 场景 cluster WSR 上界**（n=scenes，尊重空间相关）；
   - 同时报 **场景平均风险** 和朴素像素 WSR 作对照；
   - 接受规则仍按像素 `σ≤λ`。
   这个口径需要你确认，否则 RCPS 的 `U(λ)` 分母定义会有歧义。

**默认建议**：β 按未覆盖率；G6 先按 A 如实报，同时补 B 的保守 τ 作对照；RCPS 用“像素池化 + 场景 cluster WSR”；Mondrian 用**物理 ρ 标签**（不用网络 cls 头，避免循环）；SF 用 sf_val 目标域重标定。你如果不改，我就按这套默认继续写 RCPS 和覆盖率图。
